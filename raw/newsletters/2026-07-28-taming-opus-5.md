HOW FLORA TURNS ONE REFERENCE IMAGE INTO A REUSABLE CREATIVE SYSTEM

Every’s article headers share a visual language. In this video, Catherine Chung, a forward-deployed creative at Flora, shows how she would turn one finished image into a reusable workflow for the next article.

Catherine walks Dan Shipper through the full process: extract the visual rules from a reference, adapt them to a new topic, generate three distinct directions, and package the workflow so a teammate can run it without touching the node canvas.

 * Catherine asks Claude to describe the collage quality, illustration style, composition, and color application of an existing Every header image. That description becomes the template for future prompts.
 * She connects new article context to the template, splits three concepts into separate image nodes, then saves the finished canvas as a Flora Technique with one input and three outputs.

Here’s how you can get started:

 1. Pick a reference image that captures the visual language you want to reuse.
 2. Ask a model to describe only the qualities you want to preserve: the medium, composition, illustration style, color treatment, and other relevant constraints.
 3. Give it the new topic or full article and ask for three concepts built from that template, each with a different subject or composition. Render each concept separately.
 4. Once the workflow produces useful results, save its input, prompts, and outputs as a reusable Technique that teammates can run from FLORA’s app mode.
