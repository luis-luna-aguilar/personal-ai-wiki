AI Twitter Recap
Top Story: Grok 4.5 release
What happened
xAI/“SpaceXAI” publicly launched Grok 4.5 as a new coding-and-agents-focused frontier model, positioned on capability-per-dollar rather than absolute benchmark supremacy.
Elon Musk first said Grok 4.5 would be made public “tomorrow” based on strong beta feedback, calling it “Opus-class,” but faster, more token-efficient, and lower cost @elonmusk [ https://substack.com/redirect/14e935c1-dd18-4a44-ba43-e0e323506d80?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Musk later framed Grok 4.5 internally as “roughly comparable to Opus 4.7, but much faster,” emphasizing usefulness to Tesla and SpaceX engineers over benchmark chasing @elonmusk [ https://substack.com/redirect/18f15eef-9066-40da-b990-4684e0ecac4a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
The official launch came from xAI’s account, describing Grok 4.5 as “our first model trained specifically for coding and agents,” trained with Cursor, and offering “frontier intelligence at leading speeds and cost efficiency” @SpaceXAI [ https://substack.com/redirect/47d0b1a5-f66a-4b7c-9f68-d29929479ef7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Cursor said it partnered with xAI to train Grok 4.5, called it “our most powerful model yet,” and stressed that it was “the first we’ve built for more than software engineering” @cursor_ai [ https://substack.com/redirect/d34d84d5-47fe-4170-8fd2-1626c5a662aa?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Cursor also announced in-product availability with “double usage for the first week” @cursor_ai [ https://substack.com/redirect/ff8763aa-3a81-4ab0-a17c-48f81e6478c8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Cursor clarified that “Grok 4.5 and Composer are two different model weight classes,” and that Composer 2.5 would remain available with future models in that smaller class @cursor_ai [ https://substack.com/redirect/7c0079ba-4fd5-4613-a8e6-6d024c4903c8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Early ecosystem support appeared immediately: Grok 4.5 became available in Grok Build/API/Cursor @milichab [ https://substack.com/redirect/70a98b6d-f10b-41e2-9099-c38c299eb26d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], day-0 support was announced for Hermes Agent @Teknium [ https://substack.com/redirect/e7231bed-b91c-4648-a99c-5f99bd0592ef?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and later live availability in Hermes Agent/Portal/OpenRouter/Grok subscriptions was confirmed @Teknium [ https://substack.com/redirect/3b347be8-9a0c-4980-b0c8-0dddd3651c56?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Musk said the context window would likely move from 500k back to 1M “by next week” @elonmusk [ https://substack.com/redirect/8d075ce7-b700-486c-a631-8b780f1537fc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Official claims and product details
Positioning
Officially, xAI’s message was not “best overall model,” but near-Opus quality with materially better economics and speed:
“Opus-class model, but faster, more token-efficient and lower cost” @elonmusk [ https://substack.com/redirect/14e935c1-dd18-4a44-ba43-e0e323506d80?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
“First model trained specifically for coding and agents” @SpaceXAI [ https://substack.com/redirect/47d0b1a5-f66a-4b7c-9f68-d29929479ef7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
“Frontier intelligence at leading speeds and cost efficiency” @SpaceXAI [ https://substack.com/redirect/47d0b1a5-f66a-4b7c-9f68-d29929479ef7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
“Most powerful model yet” and “first we’ve built for more than software engineering” @cursor_ai [ https://substack.com/redirect/d34d84d5-47fe-4170-8fd2-1626c5a662aa?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
This framing matters: xAI is explicitly targeting the coding-agent workflow market that has recently been dominated by Anthropic/OpenAI/Cursor-style tool-using systems, not just general chat.
Pricing and context
The concrete numbers that surfaced:
Official pricing: $2 / 1M input tokens, $6 / 1M output tokens @scaling01 [ https://substack.com/redirect/c53698bf-f956-4be3-a38f-e5aea3907919?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
Artificial Analysis repeated the same price point and added:
cache hits discounted by 75% to $0.5 / 1M tokens
long inputs over 200k tokens cost double
500k context window, down from Grok 4.3’s 1M
vision input retained
configurable reasoning retained @ArtificialAnlys [ https://substack.com/redirect/43f390ad-1495-430b-b525-1ecb0d491caf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
Musk later said the context window would probably upgrade back to 1M soon @elonmusk [ https://substack.com/redirect/8d075ce7-b700-486c-a631-8b780f1537fc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Relative pricing comparisons cited by users:
Grok 4.5: $2 in / $6 out
GPT-5.6: $5 in / $30 out
Opus 4.8: $5 in / $25 out @kimmonismus [ https://substack.com/redirect/acf9a539-281d-4a4e-910a-cb505de683be?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
Model size
One important spec surfaced via third-party reporting of Musk’s disclosure:
Grok 4.5 is 3x larger than Grok 4.3 at 1.5T parameters @ArtificialAnlys [ https://substack.com/redirect/43f390ad-1495-430b-b525-1ecb0d491caf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]
That is a notable jump, and likely central to why multiple observers interpreted 4.5 as xAI’s first entry into the true flagship coding-agent tier rather than an iterative refresh.
