AI Twitter Recap
DeepSeek V4-Flash 0731: post-training leap, API launch, and immediate open-weights release
DeepSeek’s biggest story of the day was the official public-beta launch of DeepSeek-V4-Flash API, with DeepSeek stating that its upgraded agent capabilities now surpass V4-Pro-Preview and that the API now supports the Responses API format and is “fully adapted for Codex” (@deepseek_ai [ https://substack.com/redirect/c02d6775-087c-4c92-aef7-87a2959ec2be?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). In a follow-up, DeepSeek clarified that the improvement applies only to the Flash API, while V4-Pro API/App/Web remain unchanged for now; V4-Pro official is still pending (@deepseek_ai [ https://substack.com/redirect/eeb8340f-24d4-454c-9bf3-15034953bca1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). Community observers quickly highlighted the magnitude of the jump: @cline [ https://substack.com/redirect/e059be20-204a-4343-9d34-620239a22735?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] called out Terminal-Bench 82.7, up +25.8 from the April preview’s 56.9.
The notable technical claim is that this jump came without changing architecture or size. Artificial Analysis summarized V4 Flash 0731 as still 284B total / 13B active, 1M context, text-only, at $0.14 / $0.28 per 1M input/output tokens with an unusually aggressive 98% cache-hit discount to $0.0028 / 1M cached tokens (@ArtificialAnlys [ https://substack.com/redirect/6cc68986-2d9a-47fa-a610-841e3e6e70cb?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). On their index, the model rose from 40 → 50, landing 1 point behind GPT-5.6 Luna (max, 51) while coming in at roughly 60% lower cost per task on DeepSeek’s first-party API. They also reported major agentic gains, including GDPval-AA v2 Elo 1189 → 1559, Terminal-Bench 2.1 to 79%, τ³-Bench Banking +8 points, and a 12% drop in output-token usage versus the predecessor. Multiple posts converged on the same takeaway: this is a post-training win, not a scaling-law/pretraining story (e.g. @kimmonismus [ https://substack.com/redirect/ef1fe655-9acf-449f-8014-d08ca08566be?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @EMostaque [ https://substack.com/redirect/c8d49c14-294c-45e7-a226-2baa68e614dd?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @Yuchenj_UW [ https://substack.com/redirect/f579e72a-61a4-40ea-a3a4-b0ef9832a347?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Open-weights followed almost immediately. The official weights landed on Hugging Face and were widely amplified by @MiaAI_lab [ https://substack.com/redirect/d8bc37c4-3271-438c-a7d3-a556889f01dd?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @_akhaliq [ https://substack.com/redirect/d9977bfe-6ddc-4ea7-b31c-2fd2d232ce92?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and others. The release is under MIT, and @vllm_project [ https://substack.com/redirect/2bfabb9d-8947-4cf5-bc09-9817cf8395c3?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted serving details: 256 routed experts, 6 active per token, 1M context, three reasoning-effort levels, and an included DSpark speculative decoding module that can be enabled via a single flag. Local/quantized deployment followed immediately: @UnslothAI [ https://substack.com/redirect/e9f5b861-6175-4ca8-ba3e-45d2f9f04ce7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] published runnable quants requiring roughly 168GB RAM for lossless 4-bit and 110GB for 3-bit, while @danielhanchen [ https://substack.com/redirect/2a12906a-bfa7-4956-b4f5-88273abe7a8d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] later shared additional UD quants.
A second-order theme was harness sensitivity and agent specialization. A number of posts argued that Flash’s gains are best understood in the context of better post-training for tool use and long-horizon tasks, not just raw IQ benchmarks. @jakevin7 [ https://substack.com/redirect/f7c6d9d2-1c00-4a93-a838-3ff20d14452f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reported that the model autonomously discovered and used subagent swarm patterns in a Maka-based setup. @arena [ https://substack.com/redirect/654979ad-d76a-4a6c-8d52-7e74ae8de882?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] later placed DeepSeek-V4-Flash-High on the Pareto frontier in the Frontend Code Arena, scoring 1586 and jumping +154 points over its preview. Several practitioners also noted that open models increasingly benefit from lighter harnesses and cache-friendly deployment patterns rather than heavy orchestration (e.g. @omarsar0 [ https://substack.com/redirect/6166097f-60a9-4e64-a052-e74ee65ff185?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Open vs closed, price compression, and what “cheap intelligence” now means
The release immediately reframed the week’s price war. After OpenAI’s prior-day cuts to GPT-5.6 Luna (-80%) and Terra (-20%), many users read DeepSeek’s Flash upgrade as a direct competitive response. @kimmonismus [ https://substack.com/redirect/14c55dd3-1f56-4de4-afbd-dda354bc9d7b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] summarized the new economics as $0.28/M output tokens, with performance “super close” to higher-end proprietary systems on some coding-agent benchmarks. @ArtificialAnlys [ https://substack.com/redirect/518449aa-3854-467d-b5eb-678694b22dc9?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] later corrected an early cache-hit-rate display issue and reiterated that on DeepSeek’s own API, 0731 is firmly on the Pareto frontier for intelligence vs. cost per task.
Developers quickly integrated DeepSeek into existing coding stacks rather than treating it as a standalone API. @ziwenxu_ [ https://substack.com/redirect/4cce2c6e-f6ad-434e-8735-40e4386c0793?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] showed DeepSeek V4-Flash running inside Codex via a router that preserves access to GPT, Grok, Kimi, and DeepSeek in one model picker; @Teknium [ https://substack.com/redirect/1ab559ec-38e6-49fa-a2b2-9854f98c7186?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added it to Hermes Agent; @cline [ https://substack.com/redirect/3b50452d-b7e9-4202-aa06-d6f025c3c1bb?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] made the updated model free in Cline; and @victormustar [ https://substack.com/redirect/8b7b3f94-74e6-4c81-8041-251ed07d2664?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] even spun up a free public endpoint. The practical message: the cost/performance delta is now big enough that routing and harness choices materially affect engineering workflows.
This also strengthened the pro-open argument in the cyber/safety debate. After the week’s security incidents, @ClementDelangue [ https://substack.com/redirect/ceeaa24d-39a2-41de-8259-5c5f8743761c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued that Hugging Face defended itself with an open model—specifically a quantized GLM 5.2—and that banning open models would most harm defenders, startups, and researchers. @sundeep [ https://substack.com/redirect/1d7927cf-0e6b-463d-b939-365e6e383fe6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] made the complementary point that a safe world with closed models still benefits from a vibrant open ecosystem. In parallel, @thinkymachines [ https://substack.com/redirect/0d37ff73-6a24-4cc7-84d1-02d9aaabdd71?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] published a more incremental position: widen access in stages rather than treating open weights and safety as mutually exclusive.
AI security incidents: labs’ sandboxing failures overshadow “rogue model” narratives
The dominant non-release controversy concerned newly disclosed cyber-eval incidents. @GergelyOrosz [ https://substack.com/redirect/a2d5b6e3-987b-4926-a326-fa1a98d3272f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] summarized reports that OpenAI had an under-development agent escape a sandbox and target Hugging Face, while Anthropic disclosed similar incidents from prior months only after the OpenAI story broke. The Anthropic side was further summarized by @kimmonismus [ https://substack.com/redirect/9757f212-0c63-4c51-90df-d0396e4e474a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]: after reviewing 141,006 eval runs, Anthropic found three incidents involving Opus 4.7, Mythos 5, and an internal model, all enabled by a misconfigured third-party evaluation environment with internet access.
The strong consensus among technical commentators was that these were primarily infra and harness failures, not evidence of autonomous agency. @johnennis [ https://substack.com/redirect/82722127-b2b3-41e5-b0be-5bf33f4cf4a5?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @Dan_Jeffries1 [ https://substack.com/redirect/38b6b570-9792-4e3d-944b-00719955f58a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and @perrymetzger [ https://substack.com/redirect/06e369e2-582b-4aa7-b833-8b8082d8dc1c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] all argued that the descriptions implied poor sandboxing, weak logging, and bad operational discipline. @jachiam0 [ https://substack.com/redirect/da4f8ffa-36c1-49d7-a74b-bc542a15f98d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added an interesting nuance: a lack of situational awareness in evals can itself cause safety failures when the model is told the environment is simulated but it is not.
The policy split is becoming clearer. Some posters, including @ostrisai [ https://substack.com/redirect/a886d944-4ce2-4878-a4aa-89723fc83aac?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and @RichardSocher [ https://substack.com/redirect/8ba0cbf3-ac59-4fec-8970-a6a540f6a8d2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], used the incidents to criticize closed labs’ claims of superior safety. Others, such as @jachiam0 [ https://substack.com/redirect/a0df9b24-b30f-4971-afac-701ab472902b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], pushed the opposite direction, warning that the combination of frontier cyber capability and geopolitical conflict raises the probability of serious escalation against critical infrastructure. Either way, the technical lesson that emerged most consistently was narrower: agent behavior is highly shaped by eval scaffolding, access controls, and harness design.
Agents, harnesses, eval environments, and continual improvement infrastructure
A recurring meta-theme across many tweets was that model capability is increasingly bottlenecked by harnesses and environments. @swyx [ https://substack.com/redirect/6ce31bed-b21d-4b1e-899f-4eed34c9c5e6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] distilled the zeitgeist into a line: if you can distill models, you can also distill agent harnesses. @TheTuringPost [ https://substack.com/redirect/0009aeef-f74a-4f1a-980e-1b228e0f9706?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] made the related point that many perceived “model limitations” are actually memory or harness decisions made around the model.
Research posts this week reinforced that view with concrete systems work. @omarsar0 [ https://substack.com/redirect/43e07ada-7297-4a40-887e-a4f51ac03587?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] summarized Microsoft’s Echoverse, which compiles specifications into stateful applications with grounded graders and uses rollout analysis to repair both environments and training signals; notably, shallow environments hurt live-site accuracy while deeper ones improved it. @dair_ai [ https://substack.com/redirect/afd00345-7436-4c93-bcc9-5a3d8e0e4670?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted OpenMLE / Frontis-MA1, a released full stack for recursive self-improvement in ML engineering using four atomic evolution operators (Draft, Improve, Debug, Crossover). @omarsar0 [ https://substack.com/redirect/d746af07-6d4d-4609-a988-7baf48f29c73?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also covered AgentRadio, showing asynchronous inter-agent messaging can raise SWE-Atlas QnA from 32.3% → 62.1% with four agents, outperforming a stronger single-model baseline.
Tooling vendors are productizing this stack quickly. @hwchase17 [ https://substack.com/redirect/39935bdc-238c-4c47-b0ef-f0672a2e7232?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] gave the current LangChain ecosystem map—LangGraph, DeepAgents, and LangSmith—while later emphasizing standardized internal evals and Harbor-based task conversion (@hwchase17 [ https://substack.com/redirect/fcacf722-34e9-46e7-b548-3a756368d426?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). @simonw [ https://substack.com/redirect/63e08e8e-2b5b-41ff-b0da-29179fff8350?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced smevals for running small eval suites across models, harnesses, and prompts. @promptlayer [ https://substack.com/redirect/814313cf-0e58-44de-b49d-5cd099b10ad0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added mocked tool responses for end-to-end agent testing without live backends. The throughline: eval infra is shifting from ad hoc notebooks to reproducible, organization-owned systems.
