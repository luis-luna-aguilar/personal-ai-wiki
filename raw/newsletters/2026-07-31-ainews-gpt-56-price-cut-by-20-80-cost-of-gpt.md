One of our big “hero charts” a year ago (eventually adopted by Demis [ https://substack.com/redirect/311a7c3c-b8f0-4071-abb9-4661ad989198?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]) made the stunning observation that, holding LMSys Elo constant, GPT4 level intelligence fell by 1000x over 18 months [ https://substack.com/redirect/27baaf8a-56fd-45e4-affd-bdf7864b7899?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]:
Back then, it was unclear if these were “noob gains” - going from unoptimized to optimized, going from completions to reasoning, going from dense to MoE, with all the low hanging fruit gone. Another 18 months later, it seems the answer is no; constant-level intelligence is continuing to get precipitously cheaper.
Yesterday, OpenAI published [ https://substack.com/redirect/a5400cf1-976d-4a62-ad44-69096230e17d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] findings on how GPT 5.6 had optimized its own serving:
1. Inference Acceleration
To serve more tokens on the same hardware without sacrificing quality, OpenAI focused on several systemic upgrades:
Self-Optimization: GPT-5.6 Sol was actively used to analyze production traffic, tune load balancing, and autonomously rewrite production kernels in OpenAI’s own Triton and Gluon languages. This autonomous kernel optimization reduced end-to-end serving costs by 20%.
Speculative Decoding: Improved its own draft model (by designing and running hundreds of experiments on its architecture, testing changes in size, structure, and features, while monitoring the speculator training process, autonomously intervening when issues arose, including hardware failures and training instability) increasing token-generation efficiency by over 15%.
KV Caching: Optimized batching, sharding, and cache management specific to different workloads (primarily Sol in Codex) to extract more inference from existing hardware.
2. Agentic Harness Improvements
To streamline the complex, multi-step tasks in tools like Codex and ChatGPT Work, OpenAI optimized their Rust orchestration layer to reduce repetitive compute costs:
Avoiding Context Bloat: Tools, skills, and plugins are only surfaced when needed (deferred discovery), and tool outputs are capped at 10,000 tokens by default to prevent the context window from expanding unnecessarily.
Prompt Caching: To avoid reprocessing the same instructions and history repeatedly, the harness treats all model-visible history as append-only. This preserves the prompt prefix, allowing the system to reuse previously computed data and maintain a high cache hit rate.
Today, they proved it wasn’t just theory, announcing large price cuts for the smaller models and a new 2.5x Faster mode in Sol (though not the hinted 10x faster Cerebras-driven mode promised in July):

Good, but what is truly jaw dropping is Nicdunz’s observation [ https://substack.com/redirect/83dac183-86a9-45c0-a02b-4f0e167602f0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]:
GPT-5.4 full at xhigh scored 51, exactly where Luna max sits today. GPT-5.4 costs $2.50/$15; Luna now costs $0.20/$1.20. In other words, roughly four months later, OpenAI is selling March’s full flagship intelligence at about one-thirteenth the token price.
That’s an annualized rate of ~2000x a year, a huge acceleration since our last observation - which you SHOULD discount because all public benchmarks like AA’s get trained to some extent whereas Elos are less directly trainable. While leading Chinese and American open models like Poolside’s Laguna [ https://substack.com/redirect/845cef9b-71d1-4cf5-a64d-4f46a0aa463e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and Thinky’s Inkling [ https://substack.com/redirect/28560500-9b52-4f9b-ab76-0ab713f154be?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] offer full control and sovereignty, if your only goal is cost-effective non-finetuned intelligence, you will find it -very- hard to beat OpenAI right now.

OpenAI Pricing Cuts, Harness Semantics, and the ARC-AGI-3 Memory Debate
OpenAI cut GPT-5.6 prices aggressively and added a faster Sol tier: OpenAI [ https://substack.com/redirect/6e4299c4-c85c-454a-9c7d-0f173e95d492?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reduced GPT-5.6 Luna by 80% and Terra by 20%, while introducing Sol Fast at up to 2.5× lower latency for 2× the standard price with “no change in intelligence,” per @OpenAIDevs [ https://substack.com/redirect/ad7c729e-d3dd-4640-94cb-60e1b8a4f4a1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The downstream effect is notable for agent workflows: Auto-review in ChatGPT app and Codex CLI is moving from GPT-5.4 to Luna [ https://substack.com/redirect/1a3290ec-7ebc-4603-bce0-301043191dfc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], with OpenAI expecting roughly 10× lower cost. Multiple observers framed this as a meaningful shift in the price/performance frontier, including @sama [ https://substack.com/redirect/7a733418-048a-4376-90ba-54395ca0f744?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @nicdunz [ https://substack.com/redirect/83dac183-86a9-45c0-a02b-4f0e167602f0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and @kimmonismus [ https://substack.com/redirect/fe00a735-65b5-4e89-8c65-295e4160bae5?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. OpenAI also tied the cuts to systems-level efficiency improvements spanning “model, inference stack, and agentic harness” per @OpenAIDevs [ https://substack.com/redirect/4bd42718-3a61-4dd6-87b3-8c2236ff9479?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
ARC-AGI-3 re-emphasized that “the model” is not the whole system: The most technical eval discussion centered on harness design, memory retention, and context compaction. François Chollet [ https://substack.com/redirect/e6803c80-02a4-4a74-888e-04376c0bd145?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] clarified ARC’s rules: bespoke benchmark-specific harnesses are disallowed, but general-purpose API features available to all users are acceptable if settings and cost are reported. A detailed summary from @kimmonismus [ https://substack.com/redirect/dfb2ed31-48a8-4880-89d5-4161962cca34?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] contrasted Opus 5 at 30.2% on the official semi-private ARC setup with GPT-5.6 Sol at 7.8% under the standard harness, while noting OpenAI’s internal use of Responses API retained reasoning + compaction raised Sol’s public-set score to 38.3%. The takeaway echoed by @gneubig [ https://substack.com/redirect/345f7a2e-ffdb-4e9c-99f8-6ff34b683017?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @scaling01 [ https://substack.com/redirect/56cf4a0d-3be5-4ea5-9290-86a0d76a9327?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and others: long-horizon evals increasingly measure the complete agent system—reasoning retention, truncation policy, compaction, tool orchestration—not just base weights.
Thinking Machines’ Inkling-Small and the Continuing Open-Weights Push
Inkling-Small compresses Inkling-class capability into a much smaller active footprint: Thinking Machines [ https://substack.com/redirect/28560500-9b52-4f9b-ab76-0ab713f154be?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] released Inkling-Small, an open-weights, natively multimodal MoE model with 276B total parameters and 12B active, positioned as delivering performance comparable to the original Inkling at roughly a quarter the size. The company says it processes audio and images jointly with text and supports Python-based image inspection during reasoning in multimodal settings, per their follow-up [ https://substack.com/redirect/a726fa00-f654-4ab0-a6ea-000b5fc66155?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The release immediately landed across the open inference stack: vLLM announced day-0 support [ https://substack.com/redirect/0720fd1b-ada6-488e-b4bb-9783eb315f20?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Modal highlighted single-B300 deployment [ https://substack.com/redirect/c8ed4e64-a582-4c16-b96f-1e4a47a40706?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], LMSYS/SGLang reported decode throughput figures [ https://substack.com/redirect/5d0ffc5d-0135-42d6-a35b-2938d4389bd6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and Unsloth published a local-running/GGUF guide [ https://substack.com/redirect/cde2a685-038a-4ca2-a97e-b97c2547c528?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Benchmarks suggest an unusually efficient open model for coding and multimodality: Artificial Analysis [ https://substack.com/redirect/7e8aad9d-f713-49ae-a040-9eeb8df908f8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] placed Inkling-Small at 40 on its Intelligence Index—within a point of the flagship Inkling—with strengths on Humanity’s Last Exam, GPQA Diamond, CritPt, and SciCode, though weaker on some agentic tasks and factual knowledge. Community summaries emphasized that the smaller model can beat or match the larger Inkling on several coding tasks, including @kimmonismus [ https://substack.com/redirect/f07b0b59-4798-4f6d-a564-a72475a6c119?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and @mervenoyann [ https://substack.com/redirect/454e9633-cfeb-4c0b-8af5-bdbb31fa5d20?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The combination of open weights, multimodal input, 1M-context support in deployment stacks, and 12B active compute makes this one of the more practically important open releases in the batch.
Google’s Gemini Robotics 2 and the Acceleration of Embodied AI
Gemini Robotics 2 expands from tabletop manipulation to full-body control and multi-robot coordination: Google DeepMind [ https://substack.com/redirect/d230c8e3-806e-4f90-b233-5103f1e6e7c1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched Gemini Robotics 2, describing it as “one brain for any robot,” with demos spanning whole-body humanoid control, advanced dexterity, and multi-robot collaboration. Google AI [ https://substack.com/redirect/62568075-982e-401e-8f57-ab277cd48c7e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added that the stack includes Gemini Robotics ER 2, a high-level embodied reasoning model that can observe, plan, coordinate with a VLA model, track progress, and recover from failed steps during multi-minute tasks. The demos emphasized nontrivial motor tasks such as knot-tying, screwing in a bulb, bending to pick up objects, and collaborative garage cleanup.
The practical story is heterogeneity and adaptation, not just nicer demos: Technical commentary highlighted that the same checkpoint controlled multiple hardware types and that On-Device 2 can reportedly adapt to a new two-arm robot with fewer than 200 examples, summarized by @kimmonismus [ https://substack.com/redirect/edfcb272-823e-4885-8b79-9ca7febf8234?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. @OfficialLoganK [ https://substack.com/redirect/063849f1-ef22-45a5-99a4-f6ada9fcfc7d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and @osanseviero [ https://substack.com/redirect/f58601f0-dbf9-478d-a62b-292d56b167a4?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] focused on ER 2’s API availability and embodied reasoning metrics, while NVIDIA Robotics [ https://substack.com/redirect/6fccc563-94d0-42c6-9aa0-cd1387e83780?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] used the moment to push the local hardware side with Jetson AGX Thor for humanoid/autonomous systems. Relative to prior robotics announcements, this one stood out because it combined platform breadth, planning, dexterity, and live-streaming APIs rather than a single narrow manipulation benchmark.
Agents, Cloud Development Environments, and Persistent Memory Infrastructure
Cloud agents are graduating from demos to core engineering workflows: One of the stronger operational datapoints came from Cursor [ https://substack.com/redirect/4c2263fc-9068-40d6-b24d-34ea2265696f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]: in December, 1 in 10 merged PRs came from cloud agents; now that share is 56%, attributed to giving agents their own cloud computers and allowing them to improve their environments over time. In the same vein, @jaredpalmer [ https://substack.com/redirect/1b98f7bc-1937-43f6-9c4f-669d08210c67?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] said he still hasn’t set up a laptop for local development after joining Cognition, preferring Devin in Slack/webapp, and @dabit3 [ https://substack.com/redirect/e3903cac-d6ef-4996-bf20-74e1fd362614?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] showed Devin cloud agents running macOS with Xcode and simulator access to build/test native iOS apps. Cognition [ https://substack.com/redirect/5a69aefb-6277-41bd-abbe-ebe0cf599b63?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also added native GitHub stacked PR support, a useful adaptation for agent-generated changesets.
Persistent memory is becoming productized, but evidence on its value is mixed: Perplexity [ https://substack.com/redirect/92a1f551-21bb-43d7-b1c8-995de5199fe1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched Projects, evolving Spaces into hubs for ongoing work with shared files and persistent memory via “Brain,” while @AravSrinivas [ https://substack.com/redirect/2bdaa4e9-57f6-44a9-be76-d271eebed79a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] positioned it as a multiplayer, agentic operating system for work. For memory infra lower in the stack, TurboPuffer [ https://substack.com/redirect/0719e255-ac95-4a49-bddf-01def598a996?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described Mem0 migrating 400M+ agent memories from pgvector to turbopuffer, citing 70ms p90 hybrid retrieval and 97% recall@10. But the research signal was more cautious: @dair_ai [ https://substack.com/redirect/f3373391-294e-47a9-9ed5-dfa7fc3f8550?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted a paper suggesting filesystem-style memory stores can halve retrieval cost at scale yet did not improve final answer quality in the study, and store quality degraded under most management agents except the strongest one. Net: memory infra is maturing as a product surface, but its causal contribution to capability remains unsettled.
