## **Jer Crane’s story is a reminder of how unpredictable AI agents can be**


--------------------
View image: (https://media.beehiiv.com/cdn-cgi/image/fit=scale-down,format=auto,onerror=redirect,quality=80/uploads/asset/file/40b6f1bb-fc84-4257-9f7a-92dbd98f43e3/superhumanteam_A_robot_holding_a_stick_of_dynamite_in_an_offi_0f2e4352-56b5-4017-ac33-02e2df1da80c_3.jpg?t=1777397396)
Caption: Made with Midjourney


--------------------
**Rogue agent.** Jer Crane, founder of PocketOS, published a [viral essay](https://x.com/lifeof_jer/status/2048103471019434248) that’s racked up close to 7M views — because it reads like a modern-day corporate horror story. His AI agent went rogue, ignored strict guardrails, and deleted the company’s entire production database. It’s a cautionary tale for anyone experimenting with agents.

**Gone in 9 seconds.** Crane’s agent was completing a task when it decided to “fix” an unrelated issue. Before anyone noticed, the agent fired off a destructive command that wiped the production database and recent backups. When asked why it ignored the guardrails, the agent admitted: "I violated every [safety] principle I was given."

**Leading software.** PocketOS was running Claude Opus 4.6 inside Cursor, two of the most widely used tools in agentic coding. Crane himself has 15 years of engineering experience and set explicit rules forbidding destructive commands. The accident happened anyway, despite Crane’s best efforts.

**The good news.** While PocketOS’s data was eventually [recovered](https://www.techloy.com/claude-ai-agent-deletes-startup-pocketos-database-in-9-seconds-then-writes-confession/) after a stressful 30-hour window, the story is a sobering reminder that even today’s leading models can be unpredictable — and selectively ignorant of rules. Experiment with caution.

## **How to get better outputs with fewer tokens in Claude and Claude Code**


--------------------
View image: (https://media.beehiiv.com/cdn-cgi/image/fit=scale-down,format=auto,onerror=redirect,quality=80/uploads/asset/file/17860845-3494-485d-9249-3a98c9e312bb/Image_from_Squoosh__73_.jpg?t=1777367034)
Caption: 


--------------------
* Copy only the relevant text from your file, paste it into a Google Doc.

* Export as a Markdown file .md (under 200 tokens) and upload that into [Claude](https://claude.com/product/claude-code).

* Keep all tools/settings off by default, only turn them on when needed.

* Write prompts in a clear format: _“I want you to act as a [ROLE] to [TASK] for [GOAL], using [CONTEXT], following [CONSTRAINTS], and ask clarifying questions before responding in [OUTPUT FORMAT].”_

* Batch your requests into one message instead of multiple: _“Summarize this, list key points, suggest a headline.”_

* Instead of sending new prompts, edit your existing one.

* Start a new chat for every new topic to save tokens.

* Set your personal preferences once, so you don’t repeat yourself every time.
