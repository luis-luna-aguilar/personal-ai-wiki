The most astonishing is the how [ https://substack.com/redirect/8d099f9c-3df1-493d-ba02-6e9043bb5414?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] - while Navier-Stokes was done in 88 hours and 10,000 agents [ https://substack.com/redirect/feeb4d15-f4bc-45ae-ac56-479c478f2aaf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], these solutions were 3 hours of ChatGPT Pro on average.

AI Twitter Recap
OpenAI Releases 722 Math Manuscripts From an Unreleased Internal Model
The release: OpenAI published a broad set of mathematical results from an internal frontier model in a public GitHub repo [ https://substack.com/redirect/1ea121f8-4349-468e-b8f1-fdd21da7e564?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. It says it consulted the Institute for Advanced Study’s independent Advisory Group on Mathematics and AI on how to release them.
Scale and compute: The collection reportedly holds 722 manuscripts grouped into 372 families of related results. They came from an evaluation of about 4,000 research problems and used an average of roughly three hours of ChatGPT Pro thinking compute per result (summary [ https://substack.com/redirect/fc30fd5e-3687-42fb-ab4d-50c60f21f4e1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Rundown [ https://substack.com/redirect/77bd61ca-1a2d-4a6c-b10f-86b354964709?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Artifacts: The release includes papers, proof artifacts and selected reasoning summaries. The model itself remains unreleased.
Framing: Sam Altman called it “a new era of discovery” [ https://substack.com/redirect/9e593fd0-6d68-4d3c-b73a-ef38c8dca3f7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Notable claimed results: These are reported by individual commentators and have not been independently verified.
Integer multiplication: One contributor highlighted a result for integer multiplication faster than n log n [ https://substack.com/redirect/4a72b2ba-856d-4e17-84a8-e126b41404bf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Elastic inverse problem: Another singled out a uniqueness result for the elastic inverse problem [ https://substack.com/redirect/2329b84b-6c59-43b3-b20f-d958550984a8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], which the paper says had been open in 3D since 1994.
Millennium-adjacent work: Commenters point to partial progress on Riemann, Hodge and BSD [ https://substack.com/redirect/06b488da-93a9-4e20-b7f0-b1222eb36312?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Mathematician reaction: Levent Alpöge praised the quasi-Riemann and no-Siegel-zeros results and called it “the most significant moment in mathematical history” [ https://substack.com/redirect/22b480e9-636c-4f26-8234-da85aa189515?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. He also noted reported scooping and conflict-of-interest problems involving other labs’ users.
Composition of results: An analysis estimates about 20% of the results are disproofs or counterexamples [ https://substack.com/redirect/9e2ef5b0-30a1-42dc-b5bf-6f3771e78e5d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. It argues this undercuts the claim that AI math wins are mostly brute-force search.
Skepticism and open questions:
Errors expected: Will Depue expects that some results should not survive scrutiny [ https://substack.com/redirect/dce143d6-b288-476c-b3df-2e29702f605c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. He built citedbyagi.com [ https://substack.com/redirect/7af3c19a-139e-452c-bca6-7f8d755ebff0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] to track which human papers the release cites.
Compute framing: Teortaxes notes that three hours of compute “is not much” [ https://substack.com/redirect/cb577186-d4a6-4e81-a41d-76407fa7f000?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Generalization: François Chollet asks whether gains in RLVR-friendly math and code generalize, or whether non-verifiable domains stay bottlenecked on human data [ https://substack.com/redirect/653e03c0-606b-40e6-9347-156608ff1297?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Mistral Large 4 (”Le Chonk”): Launch, Pricing and Contested Evals
Mistral Large 4 preview: The model has 1T total parameters and 49B active, is natively multimodal and is available via API now (announcement [ https://substack.com/redirect/6556f8de-f191-47d4-87ea-2bd794be47f5?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). Open weights are promised for end of October.
Training status: The RL run is “still in flight and shows no sign of saturation” [ https://substack.com/redirect/375c4db8-7802-4f9a-8ed5-23d9ce635c82?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Compute: The model was pre- and post-trained on ~3,800 Grace Blackwells in Europe [ https://substack.com/redirect/0ee4dfb4-178c-4ae3-8fbb-bfa1054ef080?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. A larger model is training now [ https://substack.com/redirect/0ed53617-77f3-4178-99b6-cf78d27c676b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Pricing: $1.36/$4.18 per million input/output tokens, with $0.14 for cached input and 50% off for the first two weeks (Artificial Analysis [ https://substack.com/redirect/477a3a80-30cb-43c6-bc3d-72f3f3b75cbf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Context: Vals and Artificial Analysis list a 512K context window. OpenRouter lists 1M context with up to 256K output [ https://substack.com/redirect/6c1d7c6b-4e8b-4e24-b04f-0e2eb6d9a31a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Mistral’s own claims:
Human evals: Mistral says it beats GLM 5.3 on STEM, CAD and finance in human evals [ https://substack.com/redirect/6f0e47a7-3ccb-4445-b1ee-a8c002df2253?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and is on par in agentic coding.
Coding benchmarks: It reports outperforming GLM 5.3 on DeepSWE and Kimi K3 on Terminal-Bench 4 (Rozière [ https://substack.com/redirect/26b77e29-ffcd-4ffd-9aae-838b3615f43a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Blind review: In a blind Surge coding review it finished #2, behind only Opus 5 [ https://substack.com/redirect/8348d7b2-1a26-42c2-92a9-c88d7182586f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Independent measurements:
Artificial Analysis: It scores 38 on the Intelligence Index [ https://substack.com/redirect/477a3a80-30cb-43c6-bc3d-72f3f3b75cbf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], level with GPT-6 Luna (max) and the top score from outside the US and China. It scores 50 on the Cyber Index and 82% on CyberGym-E2E-AA. Cost is $1.13 per task, over 4x that of similar-intelligence open models.
Vals: It ranks #1 open-weight on HLAB and #9 among open models on the Vals Index [ https://substack.com/redirect/dddc21d7-5350-43ce-b2e7-a16885b5f550?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Heavy context use pushes its cost to $13.78 per test [ https://substack.com/redirect/f06b856c-28ce-4e3b-88d4-3b0c2b033f06?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Clinical triage: One evaluator reports a tie for #1 on 669 clinical decisions [ https://substack.com/redirect/069e2bca-a2f2-4ed3-91fd-68ae0dfd3d76?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] with zero severe misses.
Caveats and disagreement:
Refusal effect: Cline attributes the cyber lead largely to fewer refusals [ https://substack.com/redirect/17924621-247e-4f36-aa8e-2a865d4cef6c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], saying Opus 5.5 and Astra had about 40% of tasks blocked by their own safety filters.
Index gap: Critics note it trails GLM-5.3 and even GLM-5.3-Flash on AA’s index [ https://substack.com/redirect/34dfd6da-e0b6-40cc-9d5b-31ba10614134?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Open-weight claim: Hugging Face’s CEO points out it isn’t open-weight until the weights ship [ https://substack.com/redirect/ced66ca2-7699-4a37-9f97-d59aceee368d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Configuration: Mistral warns that many reported failures come from not setting  [ https://substack.com/redirect/90135275-226e-4932-8869-f0ca5dad3acf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]reasoning_effort="high".

Open-Weight and API Model Releases: Embeddings, Image, Decision Models
EmbeddingGemma 2: Google’s first natively multimodal open embedding model covers text, code, image, video and audio in one space. It is built on Gemma 4 and released under Apache 2.0 (DeepMind [ https://substack.com/redirect/faad5d2f-f93b-484a-8ff8-96b8b9a006fb?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Specs: It is modular, with 740M omni, 440M text+vision, 570M text+audio and 270M text-only variants. It has Matryoshka dimensions from 768 down to 128, 8,192 context and a reported +14% on MTEB Code (Phil Schmid [ https://substack.com/redirect/64f6eb32-ca2b-44cb-b2f1-cf9c156644e0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Footprint: It uses roughly 191–567MB of active RAM and handles up to 5.5 minutes of audio or 58 video frames per pass (Google [ https://substack.com/redirect/5a415034-39bc-475d-8b66-e6df615a49af?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Ecosystem: Day-0 support covers llama.cpp [ https://substack.com/redirect/3492487a-8220-4548-84a8-511b5e626bbe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], vLLM [ https://substack.com/redirect/905857b8-18b4-459b-988c-02f06ac0a3c9?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Ollama [ https://substack.com/redirect/ccfc7df7-52a3-4f13-8534-13e0a0236abf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and Unsloth [ https://substack.com/redirect/9a1323a0-5675-4390-b5fb-bf33801fe74a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. It also runs in the browser on WebGPU at ~20–70ms per query [ https://substack.com/redirect/f7512fc1-7f86-472e-8a7e-80653d02b9bc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Nano Banana 2.1: Google’s updated image model is rolling out across the Gemini app, AI Studio, Search and Ads (Google [ https://substack.com/redirect/31d9b2a9-e45d-47c5-ad73-3fb996b3fa21?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
