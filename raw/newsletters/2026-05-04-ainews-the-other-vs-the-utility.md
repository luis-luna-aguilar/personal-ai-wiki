Harness Engineering, Agent Orchestration, and the Shift from Models to Context Pipelines
The harness is becoming the product boundary: A recurring theme across the day was that model quality is no longer the only meaningful moat. Anthony Maio [ https://substack.com/redirect/c7eaed7d-3bd2-4c82-bc01-a99de2b4cd7e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued that lock-in comes from the context pipeline—how repo state is fetched, ranked, and compressed into the prompt—rather than from the harness shell itself. That point was reinforced by Mason Drxy [ https://substack.com/redirect/2070852b-2d3b-4bf8-9230-c42bd05a2474?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], who reported that changing prompts and middleware in the harness moved gpt-5.2-codex from 52.8% to 66.5% on Terminal-Bench 2.0, and improved gpt-5.3-codex by 20% on tau2-bench. The practical takeaway: agent performance is increasingly a joint property of model × harness × memory/context strategy, not of weights alone.
Open harnesses are maturing quickly: The most visible momentum came from the Hermes / deepagents / Flue-style ecosystem. @Teknium [ https://substack.com/redirect/cbf952be-2b50-4639-8e16-a66494ed5f2d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched Hermes Agent Kanban for visual multi-agent coordination, while @naroh [ https://substack.com/redirect/4f81e53e-4443-4784-8909-959465ca425b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] showed a Spanish-language “war room” UI over Hermes orchestration. On the LangChain side, @hwchase17 [ https://substack.com/redirect/af778ae5-0db7-42bf-bb0f-1614c34cc065?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @sydneyrunkle [ https://substack.com/redirect/15022ab9-3b2a-4716-a0d9-c15c7dd02c3d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and @LangChain [ https://substack.com/redirect/31a36369-76cb-4219-93e6-4aacb40fdad2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted deepagents/LangGraph improvements including profiles for model-specific harness configs, schema migrations, node-level error handlers, timeouts, and new streaming primitives. PyFlue [ https://substack.com/redirect/76799778-ccb1-4f5f-a349-950d19c3477f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also extended the “agent harness” concept into Python, explicitly positioning harnesses as the missing layer between raw model calls and durable agents.
Model-agnostic orchestration is becoming a design goal: Multiple tweets framed the next wave as open models + open harnesses rather than “pick one frontier API.” Vtrivedy [ https://substack.com/redirect/b6385d8a-4bb2-45f6-9c17-242fa71b9150?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued teams can get >20x cheaper agents by tuning open models inside a good harness; Mason Drxy [ https://substack.com/redirect/38066bab-ea77-4dd3-bb21-f5c3c8b4256a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described deepagents-cli as becoming a strong coding harness for Kimi, Qwen, GLM, hosted Ollama, OpenRouter, LiteLLM, Baseten, etc.; LangChain Fleet [ https://substack.com/redirect/b1087ad3-74e9-41e0-b36c-9c49875c3a06?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added multi-model sub-agent routing so different steps can use different models. This is the architectural counterpoint to API lock-in: separate the orchestration layer from the model provider.
Coding Agents, Cost Curves, and Workflow Changes
Coding-agent UX is changing developer behavior faster than benchmarks can capture: Several posts described the lived reality of coding with Codex, Claude Code, Hermes, and Devin-like systems. dbreunig [ https://substack.com/redirect/0d9e986e-5deb-4b29-9bb9-f99704c3e561?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] proposed “commandments” for agentic coding—implement to learn, rebuild often, E2E tests are gold, document intent, maintain your spec—while dbreunig [ https://substack.com/redirect/1692a51c-cc8f-4718-8420-65e9adbb29e6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also questioned whether filesystems are even the right abstraction for agents long-term. zachtratar [ https://substack.com/redirect/11926c35-cc49-4e02-ad7a-d161d44c5c6d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] sketched a Notion→meeting-notes→spec→coding-agent workflow for compressing “3 month problems” into a few days, emphasizing that alignment artifacts are still necessary even with stronger coding agents.
Pricing/billing models are clearly unstable under agentic workloads: The standout thread was @theo [ https://substack.com/redirect/28a07695-81bf-4e63-b7f1-109ed835dc45?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], who pushed a single Copilot message to 60M+ tokens, estimating tens to hundreds of dollars of inference against a $40 subscription, later updating to ~$221 of tokens for 15 messages [ https://substack.com/redirect/ce3a683d-4a71-40b2-8f49-a217f90adacc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. This is a useful signal that flat-rate pricing built for chat turns is brittle when users hand long-running jobs to coding agents. Relatedly, petergostev [ https://substack.com/redirect/49d01176-613c-4b1a-aa7e-3ba83fb0ec50?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] showed Codex UI support for visualizing usage limits, and cheatyyyy [ https://substack.com/redirect/628f5878-1225-4b13-9dda-a2e6aad0139d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] noted the new anxiety around missing cache hits when input prices are high.
Agents are spreading into adjacent workflows, not just coding: There was a steady drumbeat of “agentized” tools: reach_vb [ https://substack.com/redirect/745fa710-5442-428d-8438-76ae1834f839?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] shipped a Codex Security plugin with five AppSec workflows spanning threat modeling, vuln discovery, validation, and attack-path analysis; gabrielchua [ https://substack.com/redirect/ddcc23ec-4d25-4011-aa3f-564df80349aa?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] demoed Google Slides generation via Codex with realtime deck construction; paulabartabajo_ [ https://substack.com/redirect/f3438633-9201-4ff6-bd9c-9347eff138fe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] published a guide to building a fully local assistant on llama.cpp; and UfukDegen [ https://substack.com/redirect/0444af47-7e53-4c95-9883-b82eeb3c50d2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described Noustiny, a substantial Hermes-based video-generation workflow with story-state, character continuity, voice, and render pipelines.
Benchmarks, Evals, and “What Are We Actually Measuring?”
Benchmark design is under active revision: Several posts focused less on leaderboard scores and more on benchmark validity. Scale AI Labs [ https://substack.com/redirect/2032c13a-e02a-41a7-a348-6bca3f43ea89?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced HiL-Bench, aimed at testing whether agents know when specs are incomplete and when to ask clarifying questions; j_dekoninck [ https://substack.com/redirect/20c31327-7d5a-42f2-bd3e-83fbc7c34aac?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced MathArena as a continuously maintained evaluation platform rather than a static benchmark; Epoch AI [ https://substack.com/redirect/7d55b049-a88e-4d64-8a55-7aed14f04679?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] ran a discussion on whether benchmarks are “doomed”; and Goodfire + AISI [ https://substack.com/redirect/95c41dcb-cd4d-4b06-8f08-a90f793e4f7c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reported that models sometimes recognize they are being evaluated, with verbalized eval awareness inflating safety scores.
Data quality and eval data generation are becoming agentic problems: One of the more technically substantive papers highlighted was Meta FAIR’s Autodata [ https://substack.com/redirect/b1989042-a7c2-4739-937f-5cbd8a88276c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], described as an agentic data scientist for creating discriminative training/eval examples. The headline number was a 34-point gap between weak and strong solvers on a CS research QA task using an agentic self-instruct loop, versus 1.9 points for standard CoT self-instruct. That matters because it suggests orchestrated data generation can produce harder, more useful examples than passive synthetic data pipelines.
Context compaction and long-context evals remain unsolved operationally: @_philschmid [ https://substack.com/redirect/54befc99-0b83-40bb-92dd-c8301b7270da?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] explicitly asked for evals requiring context compaction, and gabriberton [ https://substack.com/redirect/19334636-c884-4cba-877f-d02e224e60ff?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] pointed to long-context datasets like LOFT/LooGLE-style setups. Meanwhile, jxmnop [ https://substack.com/redirect/a2f6e809-f1db-4e62-b7be-635199e9d2cc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued that true 1M-context capability still does not really work in practice, despite infra progress, and eliebakouch [ https://substack.com/redirect/aba4c1e0-c6fb-4e51-a872-df065c8221d1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] pushed back that “infra vs science” is a false split because long-context science is itself largely about making memory/compute feasible.
Systems, Training Infrastructure, and Inference Stack Updates
New parallelism and serving work continues to target long-context, high-throughput regimes: Zyphra [ https://substack.com/redirect/9aa9d0d2-adf8-4ec7-b356-3a93e25f76fe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced folded Tensor and Sequence Parallelism (TSP), claiming lower per-GPU peak memory than standard schemes and reporting on 1024 MI300X GPUs / 128K context / 8 GPUs per model copy that TSP hit 173M tok/sec vs 86M for matched TP+SP. Quentin Anthony [ https://substack.com/redirect/ab8e3fc7-cacf-4607-926e-3b89de1d461d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added that the design has been extended to MoE MLPs and will be used for larger training/inference runs.
AMD-based open-model serving is getting more serious: Alongside TSP, Zyphra Cloud [ https://substack.com/redirect/ae1e2b0f-8010-4e83-87b2-41bdf6ee9ae4?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched inference on MI355X focused on long-horizon agent workloads, initially serving DeepSeek V3.2, Kimi K2.6, and GLM 5.1 with V4 “soon.” This pairs with the broader ecosystem trend toward cheaper agent stacks built on open-weight models rather than premium proprietary endpoints.
Training optimization and rollout efficiency also got attention: rasbt [ https://substack.com/redirect/d8e6af4b-3ffa-4d7d-8a37-1adab2f75d4e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] posted another round of architecture/model-release summaries including IBM Granite 4.1 and others; kellerjordan0 [ https://substack.com/redirect/0904b08f-67cd-4858-b971-286ec4f399cf?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted NorMuon improving modded-NanoGPT optimization benchmark records to 3250 steps; TheAITimeline [ https://substack.com/redirect/69b2a499-1a7b-4e4b-a15b-7293fccf4646?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] summarized DORA, an asynchronous RL system that addresses rollout skew with multiple live policy versions and claims up to 8.2x rollout speedup and 2.12x end-to-end throughput improvement; and PSGD [ https://substack.com/redirect/5a1d9813-06bc-49b3-bd02-de276cffc8e8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] got positive nods as a still-underappreciated optimizer line.
Research, Models, and Multimodal/Scientific Applications
