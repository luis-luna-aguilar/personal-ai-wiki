Agent Products, Harnesses, and the Shift Beyond “Just the Model”
The product surface is moving up-stack: A recurring theme was that model quality alone is no longer the moat; the winning product is increasingly model + harness + workflow + UI + memory + economics. @gdb [ https://substack.com/redirect/319f79bc-9ba8-4279-9445-16881405c3d0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] put it bluntly: “the model alone is no longer the product,” while @dzhng [ https://substack.com/redirect/878f3134-165b-42fc-969c-215dc711c0c3?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued top-tier products need model <> harness <> product symbiosis. The same pattern shows up in practice: @signulll [ https://substack.com/redirect/324a3525-a2dd-4ce9-8fab-0c559e507851?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] framed ambient AI and agentic AI as the new seam of computing interfaces, and @teortaxesTex [ https://substack.com/redirect/a6bd6999-7b1a-4c1f-b8d8-76583bc76d20?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] noted that harness research still risks converging on “replicate Claude Code” instead of exploring broader interfaces.
Coding-agent product differentiation is becoming concrete: OpenAI shipped another substantial Codex update via “codex thursday no. 6” [ https://substack.com/redirect/ff6d90bc-ca25-46dc-a13e-f3c2251e146d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] with appshots, /goal improvements, remote computer use while locked, annotation mode, plugin sharing, and analytics. @gdb [ https://substack.com/redirect/7be74fde-b417-45ef-a1b9-6509edf8353c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] separately highlighted Appshots, while users reported meaningful workflow shifts: @gdb [ https://substack.com/redirect/2afb8855-568c-489d-8f1d-a062dbeffad6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] said it’s hard to remember coding before Codex, and @reach_vb [ https://substack.com/redirect/2d20c25e-017d-4553-b625-9530e0a67030?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] said they haven’t opened an IDE in over a month. But product rough edges remain: @theo [ https://substack.com/redirect/619694ce-9ddc-428e-a978-b20dce8e6519?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] praised T3 Code’s remote feature as ahead of alternatives, then contrasted it with buggy remote workflows in Codex in a follow-up post [ https://substack.com/redirect/42766607-d0da-4984-8fca-44e51c895cb2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. On the Claude side, @ClaudeDevs [ https://substack.com/redirect/1aeda828-fcc7-4d73-abb6-fa19d3bcb4fe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] expanded auto mode to the Pro plan and added Sonnet 4.6 support; @_mohansolo [ https://substack.com/redirect/62e2cad5-821b-4f6e-9350-6c7856a53105?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also had to clarify and patch IDE support in Antigravity 2.0 after user backlash.
Model Performance, Cost Curves, and Frontier Competition
DeepSeek’s pricing move was the biggest market signal: @deepseek_ai [ https://substack.com/redirect/5da30b57-968a-4d8a-83ff-59b354fdd6f1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] made the 75% DeepSeek-V4-Pro discount permanent, triggering strong reactions because it materially changes the cost/performance frontier. @ArtificialAnlys [ https://substack.com/redirect/b7cadf39-29ae-476b-ab65-6bdd59434726?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] quantified first-party pricing at $0.435/M input, $0.87/M output, $0.0036/M cached input, estimating a blended ~$0.18/M and placing V4 Pro on the Pareto frontier for intelligence vs run cost. They estimate running their Intelligence Index on V4 Pro costs ~3x less than Gemini 3.1 Pro Preview, ~12x less than GPT-5.5, and ~19x less than Claude Opus 4.7. Community reaction centered on DeepSeek’s push toward “intelligence too cheap to meter,” as @scaling01 [ https://substack.com/redirect/301e5734-b536-46f3-a939-69549b1e4af8?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] put it. @Yuchenj_UW [ https://substack.com/redirect/c19aa43f-eda9-4cff-a9a1-8e6b0ebc8753?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and @kimmonismus [ https://substack.com/redirect/2e709209-eb30-4bd9-b298-8cb267d6204f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] both emphasized the magnitude of the cut.
Gemini Flash improved, but usage feedback was mixed: @OfficialLoganK [ https://substack.com/redirect/dd9b2b21-4d35-482f-b38b-5b729172b2e6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reported Gemini 3.5 Flash making major progress over 3.1 Pro on GDPval, claiming Flash is now “competing at the frontier,” and @Designarena [ https://substack.com/redirect/3efbc111-e2cc-48eb-a6e5-ed15a5b9f4cc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] placed it 16th overall on Design Arena, a 16-position jump from Gemini 3 Flash Preview. Protocols, Infra, and Agent Runtime Tooling
MCP’s new release candidate is a substantive protocol simplification: @dsp_ [ https://substack.com/redirect/e9187825-ab02-42eb-ac5f-ad4d73f120dc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] announced the MCP 2026-07-28 release candidate, with the key change that the protocol is now stateless: no handshake, no session ID, and any request can hit any server instance. The RC also introduces first-class extensions like MCP Apps and Tasks, plus auth hardening and a clearer deprecation policy. For infra teams, statelessness is a big operational shift: easier scaling, simpler load balancing, fewer sticky-session concerns.
Sandboxes and managed execution are becoming first-class primitives: @_philschmid [ https://substack.com/redirect/bd43fe3a-2457-4ca4-8a46-68b60e514b93?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] demoed Gemini Managed Agents + Interactions API to give an agent a secure hosted Linux sandbox with memory and code execution. @CoreWeave [ https://substack.com/redirect/fd1b82d0-a40a-4d53-baeb-51ce98c1e4f0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched CoreWeave Sandboxes in public preview for RL, agent tool use, and model eval, while @cnakazawa [ https://substack.com/redirect/02a18f65-5d67-4001-ad9d-bb84997217e6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] released Cloudsail for per-task Cloudflare sandboxes with shell, Codex, and GitHub access without exposing tokens. At the orchestration layer, @skypilot_org [ https://substack.com/redirect/4e3364ae-d051-4ea3-b19b-687fb46dd416?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued RL doesn’t work on Slurm because modern RL is a multi-service system with heterogeneous hardware and recovery needs.
Open-source harnesses and memory layers are proliferating: @NVIDIAAI [ https://substack.com/redirect/5b7ddfce-e6b3-413b-ab9c-53318d474d66?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] open-sourced AI-Q agent skills for portable deep-research pipelines that can plug into arbitrary harnesses. @Teknium [ https://substack.com/redirect/58a8ac20-2ae2-468a-8d71-58cd0c84a185?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] added Bitwarden support for key management in Hermes and later restored 256K context for Grok Build v0.1 in Hermes here [ https://substack.com/redirect/e359501f-44c4-43a1-b453-00007b691d8e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. @shannholmberg [ https://substack.com/redirect/28bda274-2d62-4eb7-b428-324305b9755c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described a shared-memory “gBrain” layer under Hermes agents, with typed folders and read-first access for specialist agents. @aakashadesara [ https://substack.com/redirect/d58504f2-0a86-44d3-9bd0-e590a834ab4e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] updated CTOP to support Devin and a CLI for listing, searching, and killing agent sessions.
Research: RL, Distillation, Architectures, and Evaluation
RL post-training and reward design are under active reconsideration: @RyanBoldi [ https://substack.com/redirect/628524d9-961b-4ebe-97d8-e7633aa12f35?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced Vector Policy Optimization (VPO), arguing scalar reward collapse during RL can sabotage test-time scaling. VPO instead optimizes vector-valued rewards, improving search performance even on the original scalar objective. @lateinteraction [ https://substack.com/redirect/b0b26178-6a04-412f-94d9-826fbf789b4d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] framed this as a way to train LLMs for more diverse environments and goals, while @FeiziSoheil [ https://substack.com/redirect/6cd57e25-2677-4229-a045-b8e715de81e1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] connected it to broader moves toward structured feedback instead of a single reward number. Separately, @jsuarez [ https://substack.com/redirect/6e65bfac-6bfb-46f1-9817-31f7bf7cb568?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] teased a solution to a long-standing RL problem involving extreme sparsity, with initial sweeps showing SOTA on one internal environment.
Agent compilation/distillation is emerging as a serious economic idea: @dair_ai [ https://substack.com/redirect/10179b02-a557-4698-bcf9-3359e99bc0c3?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted a paper showing a full agentic workflow—multi-step calls, tool use, scratchpads, decision structure—can be distilled into weights and run at ~100x lower inference cost while preserving near-frontier quality. This is one of the clearest technical arguments yet for compiling expensive runtime agent loops into cheaper deployable models.
Architecture work remains lively beyond vanilla transformers: @ChunyuanDeng [ https://substack.com/redirect/0d9c9832-2edd-467d-acd7-20aae6b00a58?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] introduced LT2, a linear-time looped transformer combining sparse and linear attention to make looping practical, along with a distilled Ouro-hybrid-1.4B. @ZyphraAI [ https://substack.com/redirect/3277f8a6-b0f6-49cc-af46-f08909c31560?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] shared work extending Equilibrium Propagation beyond energy-based models toward biologically realistic neurons. On MoE, @Jianlin_S [ https://substack.com/redirect/310f4838-7650-4b34-b7c7-bfd4f4467449?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] proposed Moving Quantile Balancing for sequence-level load balancing without a loss penalty. Meanwhile @allen_ai [ https://substack.com/redirect/9d75d60a-6b74-4da7-8613-a0521b9b4dbd?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] launched ArtifactLinker, which predicts which benchmarks a model is likely to set SOTA on before running them—a useful meta-eval tool amid growing benchmark sprawl.
Math and reasoning capability discourse shifted again: @cozyblaze265065 [ https://substack.com/redirect/45d46e72-fcb3-4d02-92b5-b1705bd9de40?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reported 99.46% on a multi-digit multiplication experiment using gpt-5.5 with medium reasoning and no tools, and @teortaxesTex [ https://substack.com/redirect/daa23270-d7f7-4c85-99da-b95642753910?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] noted modern LLMs can now do 100-digit multiplication without tools. That’s not a complete theory of reasoning, but it further weakens old “autoregression can’t do arithmetic” talking points.
