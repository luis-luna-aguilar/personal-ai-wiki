AI Twitter Recap
Inference Systems, vLLM 0.20, and the Hardware/Kernel Race Around DeepSeek V4
vLLM’s latest release is heavily about memory and MoE serving efficiency: vLLM v0.20.0 [ https://substack.com/redirect/37228bb0-0b6f-4632-8162-543b4557addc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] shipped with TurboQuant 2-bit KV cache for 4× KV capacity, FA4 re-enabled for MLA prefill on SM90+, a new vLLM IR foundation, fused RMSNorm for a reported 2.1% end-to-end latency improvement, plus support updates spanning DeepSeek V4 MegaMoE on Blackwell, Jetson Thor, ROCm, Intel XPU, and easier GB200/Grace-Blackwell setup. In parallel, SemiAnalysis [ https://substack.com/redirect/29d39a4d-9eff-4265-8cd5-32e87c53be50?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted early DeepSeek V4 Pro serving results on B200/B300/H200/GB200 disaggregated setups, claiming B300 can be up to 8× faster than H200 for this workload and pointing to upcoming vLLM 0.20 benchmarking with DeepGEMM MegaMoE, which fuses EP dispatch + EP combine + GEMMs + SwiGLU into a single mega-kernel.
DeepSeek support: several posts focused on serving tradeoffs: Jeremy Howard noted DeepSeek V4’s support for prefill [ https://substack.com/redirect/cf11035d-2f96-49c3-b333-724d9ae5941a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] as a capability many providers have dropped, while Maharshi [ https://substack.com/redirect/758ea298-04fa-4da4-b49f-527bcdad6f7b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] pointed out the overheads of dynamic activation quantization, arguing that static quantization often wins on inference speed despite calibration cost. There was also growing interest in alternate stack portability: teortaxesTex argued DeepSeek is structurally moving away from CUDA lock-in via TileKernels [ https://substack.com/redirect/55342895-ae44-45bd-abd0-208ffc2e6bad?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], suggesting model vendors may increasingly optimize for heterogeneous or domestic accelerator fleets rather than NVIDIA-only deployment.
Open Model Releases: Poolside Laguna XS.2, NVIDIA Nemotron 3 Nano Omni, and TRELLIS.2
Poolside made its first public model release with an unusually deployment-friendly open-weight coder: @poolsideai announced Laguna XS.2 [ https://substack.com/redirect/a43ffacd-3a49-433e-a069-48dbc10885dc?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], a 33B total / 3B active MoE coding model trained fully in-house, released under Apache 2.0, and advertised as able to run on a single GPU. Poolside’s broader release [ https://substack.com/redirect/42f0f936-05bc-4052-a026-91548f0d5b18?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] also included Laguna M.1 and an agent harness, emphasizing that the company trained from scratch on its own data, training infra, RL, and inference stack. Community summaries added more color: Aymeric Roucher [ https://substack.com/redirect/d4e3b393-f460-4fe0-9956-e2712a7a3356?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described two coder models—225B/23B active and 33B/3B active—with hybrid attention, FP8 KV cache, and claimed performance near Qwen-3.5; Ollama [ https://substack.com/redirect/efb94d1b-744b-4dd1-852d-802ae2730fe4?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] shipped it immediately.
NVIDIA’s Nemotron 3 Nano Omni was the day’s biggest infra-native model launch: @NVIDIAAI introduced Nemotron 3 Nano Omni [ https://substack.com/redirect/0c1cf276-6cd7-4769-82e9-8df8a973d511?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], an open 30B / A3B multimodal MoE with 256K context built for agentic workloads spanning text, image, video, audio, and documents. Distribution was immediate across the stack: OpenRouter [ https://substack.com/redirect/2acc9d67-dce6-476f-925b-da2f76323d7e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], LM Studio [ https://substack.com/redirect/857fb0a5-6108-4600-bf56-5add044eaeb1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Ollama [ https://substack.com/redirect/269d7cf1-bf92-4609-a355-6e7868680776?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Unsloth [ https://substack.com/redirect/45681d41-3a83-4db4-8800-8ca91442567f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], fal [ https://substack.com/redirect/befc2ba1-f8c3-4977-80ec-c66a448f3f43?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Fireworks [ https://substack.com/redirect/5317912e-ebc2-4918-9b54-77ad8bceba03?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], DeepInfra [ https://substack.com/redirect/96f5cc8a-140a-4ee9-8b6a-da8e0899ff3c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Together [ https://substack.com/redirect/ef0fe550-c7bc-4a04-b45c-d98d83831b38?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Baseten [ https://substack.com/redirect/b9e391ba-1cf4-4689-8094-dbb16cc85db0?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], Canonical [ https://substack.com/redirect/2b9696e5-50fe-44c5-ac69-f54323a32c42?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and others all announced same-day availability. Key specs surfaced in follow-on posts: Piotr Żelasko [ https://substack.com/redirect/ba043c35-9ee1-4c0b-8099-bba10962189d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described it as NVIDIA’s first omni release with speech/audio understanding backed by a Parakeet encoder, English-only for now, and a 5.95% WER on the Open ASR leaderboard. Several hosts cited ~9× throughput versus comparable open omni models.
Other notable model/paper releases: Microsoft’s TRELLIS.2 [ https://substack.com/redirect/aaf00d34-f514-46bc-910b-89605d7c84c3?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] is an open-source 4B image-to-3D model producing up to 1536³ PBR textured assets, built on native 3D VAEs with 16× spatial compression. On the world-model side, World-R1 [ https://substack.com/redirect/5f891000-c749-4c6a-ab11-efb4cb8eff16?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] claims existing video models already encode 3D structure and can be “woken up” with RL, requiring no architecture changes, no extra video training data, and no added inference cost.
Agents, Local-First Tooling, and Production Orchestration
Agent builders are shifting from demos to production primitives: Mistral launched Workflows in public preview [ https://substack.com/redirect/504c1fcb-e9bc-4e64-8310-b6622dd884ba?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] as an orchestration layer aimed at turning enterprise AI processes into durable, observable, fault-tolerant production systems. Related posts echoed the same theme: Sydney Runkle framed durable execution [ https://substack.com/redirect/7ec8df88-27fa-41d7-ad86-c387d89cbc20?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] as a key requirement for long-running agents, and threepointone described work on subagents / agents-as-tools with persistence, streaming, and resumption [ https://substack.com/redirect/9b5a1635-4f7f-4cd4-86a9-15a2bb76e7e6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Local/offline agents moved from aspiration to credible workflow: Teknium asserted “totally offline agents are possible” [ https://substack.com/redirect/711d9422-9d1f-441f-87c6-8871a01fe7cb?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], while Niels Rogge demoed Pi + local models [ https://substack.com/redirect/1de19c01-54c1-4a1e-9a18-8c3156d7a02a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] for desktop cleanup and Google Gemma shared a tutorial for local coding agents [ https://substack.com/redirect/491eccfd-e62c-434d-b40d-5566a4faddc7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Hugging Face’s local push also showed up in adoption numbers: Clement Delangue said 300,000 users have added hardware specs to the Hub [ https://substack.com/redirect/0e929533-4d38-4add-80de-e49ddf1756a1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] to discover what can run locally. Complementing this, Ammaar open-sourced a vibe-coding app running Gemma 4 fully on-device with MLX [ https://substack.com/redirect/cb7c93ea-d883-4b1f-a78e-bee288888793?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and Kimmonismus highlighted Sigma [ https://substack.com/redirect/9f9a778a-aeaf-4664-ac69-3fc705cc4e21?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], a private browser-based local-agent concept using open models.
Hermes and adjacent agent harnesses are gaining real-world traction: multiple posts reported Hermes outperforming OpenClaw in instruction-following or practical workflows, including SecretArjun [ https://substack.com/redirect/72a91db8-741b-4708-bc55-66a675625449?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], somewheresy [ https://substack.com/redirect/a2ffb3a6-9e41-432d-ad90-2c3c1f31b1fe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and users deploying Hermes through Telegram [ https://substack.com/redirect/baf4eed8-7e95-495e-8821-07f46c7f602f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] or for medical literature extraction [ https://substack.com/redirect/44db69d2-95f2-4c3f-b371-4e12e4a9940d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. On the research-agent side, Hugging Face’s ML Intern [ https://substack.com/redirect/50cb25fb-efe3-410e-a010-11a9838e9aa5?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] was trending among Spaces, and later gained native metric logging + Trackio integration [ https://substack.com/redirect/4943a2d6-6ac2-4631-960b-c1fdf9749386?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] to make its training jobs observable rather than black-box.
Benchmarks, Evals, and Research Findings Worth Watching
Model benchmarking remains fragmented, but a few signals stood out: Epoch reported GPT-5.5 Pro reaching  [ https://substack.com/redirect/9fce9529-5ab7-4898-86de-6a23d86f7644?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]159 on the Epoch Capabilities Index [ https://substack.com/redirect/9fce9529-5ab7-4898-86de-6a23d86f7644?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and new highs on FrontierMath—52% on Tiers 1–3 and 40% on Tier 4—including two Tier 4 problems not previously solved by any model. Separately, Greg Kamradt said ARC-AGI-3 testing for GPT-5.5 and Opus 4.7 had completed [ https://substack.com/redirect/729c3808-918e-452b-a942-86a249b8004e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], with failure modes now under analysis.
Several new benchmarks target more realistic agent and engineering behavior: Lysandre announced a benchmark for making Transformers more agent-friendly [ https://substack.com/redirect/6a1cd8e3-b81e-4dac-96ef-53f21a14fef6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and VibeBench [ https://substack.com/redirect/4931645b-980a-4ead-b13a-1b80e32bbdab?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] proposed subjective testing by 1,000 qualified software engineers to measure how models actually feel in real work. On document intelligence, LlamaIndex’s ParseBench [ https://substack.com/redirect/31ca5e58-1599-467a-80ca-3e7f258279d9?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] emphasized that OCR benchmarks miss semantic formatting such as strikethroughs and superscripts, which materially alter meaning for agents.
Research notes with concrete engineering implications: Rosinality flagged bugs in DeepSpeed and OpenRLHF that reduce SFT performance [ https://substack.com/redirect/f04c32bf-c855-4b1e-a062-86d8bc054da7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], with implications for prior studies. Arjun Kocher published a faithful implementation of Compressed Sparse Attention from the DeepSeek-V4 paper [ https://substack.com/redirect/d616c54e-0147-46f6-ba88-b7efe9817c35?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. che_shr_cat showed single-block transformers can solve Extreme Sudoku only with an explicit scratchpad and inverted routing init [ https://substack.com/redirect/c5f10f5f-5332-4242-9b6e-205e6c49d03b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], otherwise performance is zero. On optimization, Keller Jordan released a lightweight Modded-NanoGPT optimizer benchmark [ https://substack.com/redirect/dcfb69c9-a42c-43d7-b2a6-6cf2329b4507?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] designed to compare methods like Muon and AdamW on a reproducible speedrun-style task.
