**1. Thinking Machines debuts top US open-weight model: **After 17 months of building, former OpenAI CTO Mira Murati’s startup released [Inkling](https://thinkingmachines.ai/news/introducing-inkling/) — its debut model. Inkling balances strong performance with efficiency, and is built for companies to download and modify directly. It’s a notable strategy shift for a US lab, with most open-weight models coming from China (GLM 5.2, DeepSeek V4 Pro, Kimi K2.6). See how Inkling [stacks up](https://thinkingmachines.ai/model-card/inkling/#:~:text=5.-,Evaluations,-Open%20weights).

**2. OpenAI ships a physical keypad for Codex agents:** OpenAI revealed [Codex Micro](https://openai.com/supply/co-lab/work-louder/), a customizable mini keypad designed to make it easier to command agents. The keypad lets you prompt Codex verbally with a button, launch common workflows with a joystick, and adjust the AI’s reasoning power with a knob. It’s the first piece of hardware from OpenAI, but [won’t be the last](https://www.macrumors.com/2026/07/14/openai-ai-hardware-device-speaker/#:~:text=OpenAI%27s%20first%20AI%20hardware%20product%20is%20a%20mobile%20smart%20speaker%20without%20a%20display%2C%20reports%20Bloomberg.%20The%20device%20is%20at%20the%20heart%20of%20a%20new%20legal%20dispute%20with%20Apple%2C%20with%20Apple%20accusing%20OpenAI%20of%20stealing%20trade%20secrets%20that%20have%20contributed%20to%20the%20development%20of%20the%20product.). Watch the [viral release video](https://x.com/OpenAIDevs/status/2077425991790870644) (2M+ views).

**3. Anthropic launches its enterprise deployment firm: **The AI lab has teamed up with Blackstone and Hellman & Friedman to officially launch [Ode with Anthropic](https://www.ode.com/press/anthropic-blackstone-and-hellman-friedman-introduce-ode-with-anthropic-an-enterprise-ai-services-firm?utm_campaign=ode-anthropic-launch&utm_medium=referral&utm_source=superhuman), a standalone AI services firm. The goal: to help organizations move from experimenting with AI to integrating it into their operations by combining Anthropic’s frontier models with a team of experienced AI engineers and operators.

## **How to turn Figma designs into polished UI with ChatGPT**


--------------------
View image: (https://media.beehiiv.com/cdn-cgi/image/fit=scale-down,format=auto,onerror=redirect,quality=80/uploads/asset/file/cf20fd9b-bde8-48a6-ab1c-786e30962ed6/image__24_.jpg?t=1784130074)
Caption: 


--------------------
* Go to [ChatGPT](https://chatgpt.com/) and switch to the **Work** tab at the top of your screen

* Click **Plugins **→** Connect plugins **→** Browse all plugins**

* Search for and install **Figma **plugin

* Open the code project where you want to build the design

* In Figma, select the exact frame, screen, or component you want to turn into code

* Copy the link to that specific Figma selection and use the prompt below in ChatGPT:

_**Sample Prompt:**__ Implement this Figma design in the current project using the @Figma plugin: [Insert Figma Link]. First, pull the design context, assets, variables, and screenshot for the exact frame. Inspect the existing repository and reuse its components, design tokens, typography, spacing, icons, routing, and styling patterns. Make the interface responsive on desktop and mobile. Once the first version is complete, run the project, open the live page, compare it visually with the original Figma frame, and continue correcting the layout, spacing, typography, sizing, colors, and interactions until they closely match. Do not install Tailwind or introduce a new styling system unless the repository already uses it._

* ChatGPT will analyze the design, build it inside your project, and reuse your existing components

* Review the result and ask ChatGPT to fix any remaining layout, spacing, or responsiveness issues
