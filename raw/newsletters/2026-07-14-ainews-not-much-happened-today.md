Coding Agents, Harnesses, and the Shift From Chat to Execution
OpenAI’s agent products are seeing unusually strong pull: @sama [ https://substack.com/redirect/a6e8bdf8-7c91-444f-bbf6-5cc9006cca7e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] said usage of Codex + ChatGPT Work grew 2.5x in a week, later adding that GPT-5.6 Sol demand is “insane” and may cause scaling hiccups while infra catches up (1 [ https://substack.com/redirect/912a4155-277d-4617-96b0-f23c7a69c58b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], 2 [ https://substack.com/redirect/edc1ba8c-a36e-4977-8214-3def56feb57b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]). The ecosystem response was immediate: JetBrains made Codex its recommended agent [ https://substack.com/redirect/1fb6fe49-e032-4f85-8c50-391bbbffc265?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @theo highlighted Codex’s underexposed “question tool” [ https://substack.com/redirect/a7c6d5f8-13ae-4a2b-878c-8f376d531954?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and OpenAI’s own team showed command-line eval tooling built start-to-finish with GPT-5.6 [ https://substack.com/redirect/bc47dbf0-0cf7-4895-b34b-1f8158517a13?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Product-side, OpenAI also ran multiple usage resets, amplified by @reach_vb [ https://substack.com/redirect/de2c9923-ba3e-4456-ab4c-7960c7a7bc3e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and users like @kimmonismus [ https://substack.com/redirect/5b521727-9e20-4ddb-b714-6ee3942bf1e1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Harness quality and observability are becoming a first-class differentiator: several tweets converged on the idea that model quality alone is no longer enough. @swyx warned [ https://substack.com/redirect/61cbb4cc-f5d5-4079-8d2d-74aaee27b217?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] that stale agents.md instructions can act like self-inflicted prompt injection, causing multi-hour stalls in long-running tasks. LangChain added tracing for Codex [ https://substack.com/redirect/1cfca318-bf48-4a02-b9b5-dba6a020e44d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and later expanded to Cursor, Copilot, Pi, and OpenCode in LangSmith [ https://substack.com/redirect/a9050b51-2240-4e7f-8b01-7218cb57dfdd?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], exposing tool calls, subagents, and token usage. @Teknium shipped Hermes updates [ https://substack.com/redirect/09ff91b2-084f-4ea8-a76b-510ea1aed967?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] to parallelize any subset of tool calls and previously exposed banked resets directly in Hermes Agent [ https://substack.com/redirect/3ef19a7f-b242-4884-b257-399728bfd481?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The meta-point was stated crisply by @andykonwinski [ https://substack.com/redirect/a1151119-e658-4cbb-8dda-41cc2772d603?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]: companies that can encode their value into evals and environments may gain a more durable edge than those relying on capital or raw scale alone.
Open Models, Quantization, and Local Inference Compression
Aggressive compression is bringing frontier-adjacent models onto consumer devices: PrismML released Bonsai 27B [ https://substack.com/redirect/9c4d98bd-0de3-40c3-8ef4-5acd52392cbe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], based on Qwen 3.6 27B, in two compact variants: Ternary Bonsai 27B at 5.9 GB / 1.71 effective bits and 1-bit Bonsai 27B at 3.9 GB / 1.125 effective bits, both under Apache 2.0. The claim is notable not just for size, but for preserving multimodal, tool-using, long-context agentic workflows locally; a demo shows Hermes running it on an RTX 5090 [ https://substack.com/redirect/2f82105a-355b-443b-a398-4bc2738d955e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], while Locally AI highlighted phone deployment [ https://substack.com/redirect/bee1f66d-04d4-45dd-aa6c-fb40a8cd57aa?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. In parallel, Tencent Hunyuan released 1-bit and 4-bit Hy3 [ https://substack.com/redirect/366264a5-33a2-4744-ab8e-1f718bff3bc2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], describing a 295B flagship-scale model that can be served on a single GPU via llama.cpp with MTP enabled.
Quantization and edge deployment continue to broaden the open-model operating envelope: @danielhanchen announced NVFP4 dynamic quants [ https://substack.com/redirect/f451aa38-f8ea-4e02-8c77-d371fcb64e50?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] across the Gemma-4 family and additional large models including Qwen3.5-122B-A10B and GLM-4.7-Flash. @MiaAI_lab’s DGX Spark thread [ https://substack.com/redirect/db95bba0-79a8-4bed-bdcf-d7cd63bf1933?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] sketched practical multi-node local deployments, including 1M-context DeepSeek v4 Flash and MiMo-V2.5 on 2× DGX Sparks, and GLM 5.2 NVFP4 across four. The common theme across these posts is that local inference is no longer just a toy path: it is becoming viable for serious agentic workflows, especially when paired with low-bit weight formats and optimized harnesses.
Multimodal and World-Model Systems: Video, Realtime VLMs, and Motion
Realtime multimodal interaction is moving from “watch then answer” to continuous perception: OpenMOSS released MOSS-VL-Realtime [ https://substack.com/redirect/3de1b7c9-b372-40a6-8d6e-b3856130f133?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], an 11B vision-language family under Apache 2.0 with 256K context, designed for continuous video streams. Its key systems property is that it can keep watching while generating, revise or interrupt answers as scenes change, and remain silent when evidence is insufficient. A companion technical thread from @Open_MOSS [ https://substack.com/redirect/2143540e-9963-4081-aa1b-60460ad586a9?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] emphasizes a cross-attention architecture, XRoPE for unified temporal-spatial positioning, and unified templates across offline/streaming/realtime settings.
Long-video understanding is increasingly framed as active evidence search, not passive frame ingestion: a dense summary from @ZhihuFrontier [ https://substack.com/redirect/5308ba46-dd10-44cb-b098-3ab4f0c0a792?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described OmniAgent, built on Qwen2.5-Omni-7B, which uses an Observation–Thought–Action loop to request only the frames/audio it needs. On LVBench, OmniAgent-7B reportedly scored 50.5, beating Qwen2.5-VL-72B at 47.3, while consuming only ~203 frames vs 768. The training recipe is also notable: passive SFT hurt performance, while 58K agentic trajectories and entropy-weighted RL via TAURA improved it. The larger research pattern here aligns with Andrew Carr’s note [ https://substack.com/redirect/73744fc7-881e-43a4-8ec1-919ddff5ae81?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] that motion is a fundamentally novel data type requiring dedicated collection, infra, and model treatment rather than being reduced to images-with-time.
Open world models are inching toward interactive, longer-horizon simulation: @RekaAILabs outlined [ https://substack.com/redirect/4ec2e2c3-a607-4440-a279-0fbdbb8fedce?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] the data stack behind omni world models, stressing petabytes of video, 6 pipeline stages, and the doubled payoff from data-quality improvements when models both generate and understand video. @omarsar0 summarized LingBot-World 2.0 [ https://substack.com/redirect/b10fdc47-035f-4aa3-82f5-73cc92c16331?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] as one of the first open releases claiming hour-scale, 720p/60fps interactive generation, though still without long-term memory. On the application side, PixVerse Game [ https://substack.com/redirect/ffbd09c2-54ca-4727-9d75-c5e5059dfad2?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] was highlighted as pursuing the harder problem of real-time interactive video response rather than canned game-like clips.
Research Infrastructure, Benchmarks, and Evaluation Methodology
Perplexity open-sourced WANDR, a benchmark for wide-and-deep agentic research: @perplexity_ai [ https://substack.com/redirect/aabf090f-7abd-4b02-848b-2bfe32cba7b1?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] described WANDR as a 500-task benchmark built from de-identified production research tasks, requiring 170,495 source-backed records across multiple difficulty tiers. Rather than grading against a static gold set, WANDR re-fetches cited pages and checks claims against underlying evidence, which better matches dynamic web research. @AravSrinivas [ https://substack.com/redirect/a108dda7-6b11-479c-87b7-c2233a9f1ebe?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] framed this as the internal benchmark behind Perplexity Computer’s deep-and-wide research harness, while @denisyarats [ https://substack.com/redirect/db696e53-d4a2-42a2-9579-26044de0035e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] emphasized its additional role as an RL environment synthesized from production traces.
Eval design is getting more adversarial and more realistic: Agent Arena [ https://substack.com/redirect/285e1c28-094d-4929-adad-7dbd83c04fe4?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted work cutting system costs by 89% while matching the best static config’s accuracy, arguing that full system config > LLM routing alone. Relatedly, Google DeepMind work on model routing [ https://substack.com/redirect/d4de73b3-ef3b-4df6-b4db-70a6cbf64526?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] argued that routers should be judged not just by accuracy/cost but by behavioral differentiation among experts and stability under paraphrase; otherwise routing may be functionally meaningless. @HamelHusain’s automated evals post [ https://substack.com/redirect/59c16766-aba6-47a6-b865-15964f67ea53?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] landed in a similar place: these systems can spot issues humans miss, but still lack enough domain taste and feedback loops to replace experts.
Benchmarks are expanding beyond one-shot SWE tasks toward degradation and search realism: mini-swe-agent [ https://substack.com/redirect/498c19e2-7ae5-4f97-8854-57c8ed695a01?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] marked one year while now powering multiple software benchmarks; SlopCodeBench [ https://substack.com/redirect/c9ee895f-25cc-4090-a0be-32c67bb1ed3d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] was cited as measuring how agents erode codebases over sequential tasks rather than just solving one isolated issue. This broadens the benchmark surface from “can it solve a task?” to “can it avoid making the repository worse over time?”
Physical AI, Collective Intelligence, and Robotics
Sakana AI pushed collective intelligence from software into physical self-repairing systems: across multiple posts, Sakana introduced “Smart Cellular Bricks” [ https://substack.com/redirect/731d45e2-9474-4027-b67e-bf899233fdff?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], published in Nature Communications. The system consists of many identical cubes, each running a small neural network and communicating only with physical neighbors, yet able to infer global shape and detect damage without centralized control. A follow-up detail is especially notable: the cells can detect missing neighbors across six spatial directions with 95% accuracy and regrow target structures; in simulation, the method scaled to 18,000+ cubes (detail thread [ https://substack.com/redirect/0b0fc992-bf20-4dc1-93ca-f2e139dff056?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]).
Physical autonomy is also showing up in much smaller form factors: @alextoussss posted [ https://substack.com/redirect/52f51fbb-f8b4-426a-ba62-e1cfe6cfdc1b?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] a striking demo of an autonomous micro-drone achieving an air-to-air kill of a flying moth, framed as a step toward mosquito eradication. Separately, @fchollet highlighted Airtap [ https://substack.com/redirect/12309e0f-7a0d-4760-858d-feeb1ef97ceb?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], which turns SMS into a headless agentic execution layer for mobile apps, using text as the control plane and intervening only for authentication. These are different ends of the autonomy spectrum, but both point to interfaces where humans specify goals while systems handle embodied or semi-embodied execution.
