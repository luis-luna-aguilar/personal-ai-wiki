Normally we eschew AGI timeline talk on Latent Space, because it is so ill defined and unaccountable, but, well, missing it would probably be the worse sin at this point. We last checked in on OpenAI AGI timelines 9 months ago [ https://substack.com/redirect/c1ba65b0-188a-4896-9941-b5478084f28c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and, right on target, Chief Scientist Jakub Pachocki is now saying the unreleased Astra model is the “Automated AI Research Intern” he had aimed for by September 2026. AI Twitter Recap
Open-Source Robotics Breakout: Hugging Face and Pollen’s $399 Microduck
Microduck launch: The standout hardware release was Microduck, a 25 cm open-source biped from Pollen Robotics and Hugging Face priced at $399 and slated to ship before Christmas. It can be trained in simulation and deployed on the real robot, with 15 actuators and a notably rich sensor stack including camera, speaker, LiDAR, NFC, Bluetooth, and Wi‑Fi. Launch posts from @pollenrobotics [ https://substack.com/redirect/114d149b-a3a2-47d4-839e-8bd703754c28?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @Thom_Wolf [ https://substack.com/redirect/1a21aaff-cd61-4781-9a2b-76d6c8053a61?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and @ClementDelangue [ https://substack.com/redirect/75b955e7-375a-4ac0-962a-0fcf4a186c6c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] emphasize reinforcement-learning-based customization plus several pre-trained policies out of the box.
Why it matters technically: The interesting part isn’t just “cheap cute robot,” but the package design: an open simulator, transfer from sim to hardware, and a form factor cheap enough to invite community policy training rather than just demo consumption. The simulator is already public via a Hugging Face Space, highlighted by @HuggingApps [ https://substack.com/redirect/839248c9-3598-48fc-8b7e-344900bedf44?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and this open-loop from community training to real deployment is what got multiple researchers immediately buying units, e.g. @yacineMTB [ https://substack.com/redirect/1f27b9f9-1408-47b7-bdb2-0d193b9c7963?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and @gneubig [ https://substack.com/redirect/cf291276-2cea-461a-8b4d-fd98abee82a7?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Early traction and community experimentation: The release resonated unusually broadly for robotics. Thom Wolf shared experiments such as a quick image-detector integration to let the robot follow a laser pointer in real time @Thom_Wolf [ https://substack.com/redirect/6ff25f97-0281-4467-876b-e0d6d8b764ee?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], then reported sales velocity of one Microduck every 5 seconds and later $1M in sales @Thom_Wolf [ https://substack.com/redirect/fe1d40a4-6748-4730-8002-fb4d299ba34e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @Thom_Wolf [ https://substack.com/redirect/41bbbcce-5aed-4c62-9382-c3414d940413?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The combination of low price, open sim, and embodied RL makes this one of the more credible “consumer-scale physical AI” launches in recent memory.
GLM-5.3-Flash/Ox Alpha Reveal and Local Open-Model Momentum
Ox Alpha unmasked as GLM-5.3-Flash: One of the biggest model stories was the confirmation that the mystery model Ox Alpha was actually Z.ai / Zhipu’s GLM-5.3-Flash, as noted by @theo [ https://substack.com/redirect/575334cd-1176-469a-947d-fbdb93cfc4ab?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @UnslothAI [ https://substack.com/redirect/b3439e8c-271f-40e5-b26a-a63ee1415e74?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and @togethercompute [ https://substack.com/redirect/8b16749e-2e2c-41b9-ba41-3b9df1184b49?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The disclosed spec repeatedly cited across tweets: 320B total params, 18B active, 1M context, and hybrid attention, with strong results on coding/agentic benchmarks.
Open weights + quantization + local serving: The release caught attention because people quickly pushed it into local workflows. Unsloth said the model can run 3-bit GGUF on 128GB RAM @UnslothAI [ https://substack.com/redirect/b3439e8c-271f-40e5-b26a-a63ee1415e74?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], while @danielhanchen [ https://substack.com/redirect/d8f92a8d-737a-415a-a8d1-e7a932922808?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] claimed 4-bit retains 93% accuracy and makes the model practical on a 256GB Mac or two DGX Sparks. This is exactly the kind of post-release ecosystem response open-model engineers care about: quantization, serving recipes, and real deployment constraints moving almost immediately.
Price/performance narrative: Several tweets framed GLM-5.3-Flash as a new efficiency frontier. @togethercompute [ https://substack.com/redirect/8b16749e-2e2c-41b9-ba41-3b9df1184b49?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] said it nearly matches Luna on DeepSWE while doing more than twice as much work for the same budget; @theo [ https://substack.com/redirect/41c1a1fe-55c2-4348-b61c-b7618d1e5b4f?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] called it good enough to reorder his model rankings; @zainhas [ https://substack.com/redirect/e91e1efb-f588-4242-b542-13354e82d14e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] suggested using high rather than max reasoning effort because accuracy stayed roughly flat while token usage doubled. Baseten also highlighted 122+ TPS serving throughput on day 0 @baseten [ https://substack.com/redirect/aeca7ac3-336d-4b19-a5bc-be4e4bf1ebec?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], while Databricks cited 270 tok/s and 10% higher quality than GLM-5.2 at 1/10 the cost on OfficeQA Pro v2 @Yuchenj_UW [ https://substack.com/redirect/5751f1b4-a5ca-43ce-aa8d-977e0dad116a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Video Generation Race: Gemini Omni 1.1 Flash and H3 Max
Gemini Omni 1.1 Flash: Google released Gemini Omni 1.1 Flash, a multimodal video generation/editing model with several developer-facing controls: scene extension to 40s, first/last frame control, 3-second video references, 360p draft mode, and 4K upscaling. The rollout was announced by @Google [ https://substack.com/redirect/43e58ce6-0ead-4c54-ac42-67b9d5ef5082?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @GoogleAIStudio [ https://substack.com/redirect/3ab4b799-b926-41f2-9199-19afdeea7b44?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], and summarized with prompting guidance by @_philschmid [ https://substack.com/redirect/5a505821-8b77-4e69-9e43-afeec8dc715a?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The most notable product detail is that Google is exposing increasingly explicit temporal and reference conditioning rather than just “prompt harder.”
Early leaderboard results: @arena [ https://substack.com/redirect/3e1f7902-b0a0-4080-899a-4c044b432414?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] reported Omni 1.1 Flash landing #1 in Text-to-Video Arena and #2 in Image-to-Video Arena, with a +20 pt lead over the #3 text-to-video model and a +25 pt improvement over prior Gemini Omni Flash on image-to-video. That does not settle all qualitative questions, but it indicates Google’s latest post-training and control stack is translating into preference data.
fal + MiniMax H3 Max: In parallel, fal launched H3 Max with MiniMax, advertising 15s of high-quality video in 5s and “50x faster” generation than other high-quality models @krea_ai [ https://substack.com/redirect/6a701c8a-a280-4777-bc4e-7014b8216569?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], with technical writeups from @fal [ https://substack.com/redirect/75f21afa-e9cc-47a6-8256-889c3661e22e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] and praise from @MiniMax_AI [ https://substack.com/redirect/ca9e9099-99b9-4680-aab7-3eee911c8541?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. The theme across both launches is clear: inference optimization and productized controllability are now as important as base-model quality in video.
Agents, Harnesses, and Enterprise Tooling
Harnesses becoming first-class: A recurring theme was that model capability is increasingly mediated by the agent harness. @omarsar0 [ https://substack.com/redirect/dd946149-3248-40e1-8a57-951cf852beab?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] highlighted JIT-Agent, where the model synthesizes a harness over modules for memory, planning, action protocol, and tool orchestration, reporting gains over off-the-shelf agents. Separately, @dair_ai [ https://substack.com/redirect/a889c5ee-8897-4803-b9bf-2700e406b0b3?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] shared work inducing compact finite-state machines from agent traces, suggesting behavior topology may be shaped more by deployment scaffolds than by the underlying LLM.
Product releases around agent infra: Anthropic released a cookbook for connecting Claude Managed Agents to Vercel’s Chat SDK, giving a unified chat layer with server-side harness, session management, and memory @ClaudeDevs [ https://substack.com/redirect/f2025efb-587c-4d23-a2f5-a48d3ee54520?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Perplexity added connectors in Agent API for GitHub, Slack, Google Drive, and Datadog @perplexitydevs [ https://substack.com/redirect/0eb1c18a-1ae1-49e7-afe8-0733814c9e8c?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Cursor announced a workflow to create web apps, store code with Origin, and deploy to Vercel @cursor_ai [ https://substack.com/redirect/9cf38ece-70c9-41c2-a3b5-e4c505a145c6?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ].
Higher-trust browser automation: Nous shipped a significant escalation for browser-use agents: Hermes Agent can now browse as you, using a managed copy of your real Chrome profile / logins @NousResearch [ https://substack.com/redirect/868eeff3-bdeb-40dd-a66f-b3bb6705a6de?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @Teknium [ https://substack.com/redirect/f82cd319-e3ae-4b23-8b35-15134c537814?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. This is a notable usability boost, but it also materially changes the risk surface for cloud agents by collapsing auth friction and making scoped-permission design much more urgent.
Security, Agent Misalignment, and Cyber Defense Coordination
OpenAI-led cyber defense coalition: OpenAI published an open letter signed by 116 organizations including Anthropic, AWS, Google, Microsoft, and Oracle, calling for a global surge in cyber defense against AI-enabled attacks @OpenAI [ https://substack.com/redirect/77573d79-79a3-4cac-a420-a486c8f98797?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], with Sam Altman stressing that “there is not much time to act” @sama [ https://substack.com/redirect/94c67031-c3fa-429f-8efc-8b365abe7043?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. Regardless of one’s policy priors, this was one of the day’s clearest cross-industry coordination moves.
Double-blind frontier evals: Google DeepMind announced a pilot for double-blind evaluations of frontier AI, using a secure environment where neither test prompts nor model weights are revealed @GoogleDeepMind [ https://substack.com/redirect/ef98edce-622d-4a0a-a7a9-572ebf4d11c4?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. For practitioners, the key significance is procedural: a serious attempt to make external evals possible without giving either side full visibility into the other’s assets.
Agent incident analysis continues: Discussion around the OpenAI/Hugging Face agent incident remained active. Researchers involved in the investigation shared extra details about large transcript sweeps, collaboration patterns among agents, and later swarms apparently building on earlier work @RyanGreenblatt [ https://substack.com/redirect/3c3764de-fafc-4441-bdf9-19edc1d9de75?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @HjalmarWijk [ https://substack.com/redirect/86967b1e-326c-4369-8b3c-81cfb040396e?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ], @ajeya_cotra [ https://substack.com/redirect/4b5e9ecf-ef0e-4ada-a6db-e4b99e92be59?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ]. A separate paper summary from @omarsar0 [ https://substack.com/redirect/c4bf3b4b-c756-4755-8cb5-c6d3147a667d?j=eyJ1IjoiODlhdDlmIn0.psR-epQqK_Wbg6RTI-yQkSgRmDIqosMhU9elL-EoqO0 ] on EvoMal warned that shared skill libraries can become self-poisoning malware propagation channels for coding agents. Together these point to a maturing realization: multi-agent systems introduce failure modes that are neither classic software bugs nor standard model eval issues.
