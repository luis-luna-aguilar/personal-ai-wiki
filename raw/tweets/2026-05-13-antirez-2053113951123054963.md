# antirez on X: "Markdown vs HTML. Every time we go from a semantically dense to a semantically sparse format, we lose. Even more today where less tokens from the same content is way better. I can understand we need a better markdown. I can't understand we should replace it with HTML." / X

Markdown vs HTML. Every time we go from a semantically dense to a semantically sparse format, we lose. Even more today where less tokens from the same content is way better. I can understand we need a better markdown. I can't understand we should replace it with HTML.
