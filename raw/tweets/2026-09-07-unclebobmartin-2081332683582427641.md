# Uncle Bob Martin — AI agents free up time for exhaustive testing

2026-07-26, @unclebobmartin (266K followers, 5,477 likes / 379K views on the lead tweet).

**Lead tweet:** "AI agents can write code many times faster than a human. What this means is that you, the programmer, have a large amount of time to use those agents to write unit tests, to write acceptance tests, to write property tests, to torture test, to mutate test, to QA test, and to otherwise ensure that the code meets its functional and quality requirements. And even after spending all that time, you will still be many times more productive than a human programmer, and the result will be better."

**Follow-ups from Martin:**
- "Look at the git timeline of github.com/unclebob/missile-command" (a dual-platform Clojure/ClojureScript Missile Command remake) — offered as a worked example.
- "I had my agents built a little dependency checking tool. With that tool I can specify a dependency architecture. The agents then enforce that architecture for me. I also had the agents write a little architecture viewer for me. It shows me the architecture in UML."

**Notable pushback in replies:**
- @cryptohustler04: "More tests don't mean better code" — Martin's reply: "Unless, of course, some of those tests check for code quality."
- @marco_rotili: "The problem with this approach is that it is hard to test and verify architecture. Agents are quite good at making tests pass but the overall big picture is still a mess. But we will get there with better tooling." (68 likes)
- @notatechguru: "In theory, yes. In reality, most teams are just using that extra speed to push 10x more untested slop into main and leaving the unit tests for 'later'." (42 likes)
