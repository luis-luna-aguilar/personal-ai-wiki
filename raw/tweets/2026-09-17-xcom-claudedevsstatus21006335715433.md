# ClaudeDevs on X: Projects in Claude Code

**ClaudeDevs (@ClaudeDevs), Sep 17, 2026:**

Today we're rolling out Projects in Claude Code on desktop and web.

A project is one conversation with Claude. It splits the work into threads itself, runs them as parallel cloud sessions, passes context between them, and keeps going when you leave.

In beta for select users.

**Thread:**

- Available today for Pro and Max users who already run cloud sessions and haven't used Claude Projects yet. If you've used Projects before, we're rolling out to you slightly later so your existing ones move over cleanly. Want access now anyway? Join the waitlist: "Projects are becoming a conversation with Claude" (claude.com)
- Threads run in the cloud, even when your computer is not online. Support for local workflows is coming very soon. More in the docs: "Let Claude coordinate ongoing work with Projects - Claude Code Docs" (code.claude.com)
