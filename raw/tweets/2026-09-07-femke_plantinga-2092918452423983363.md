# Femke Plantinga — 9 "company brain" architectures compared

2026-08-27, @femke_plantinga (Slite; 1,736 likes, 144.3K views, 3,925 bookmarks).

"Everyone's suddenly building company brains. Nobody agrees on what's inside one. 😵‍💫 So we opened up 9+ company brains to see how they're actually built. Every single one does the same four things: getting signals, remembering, dreaming & pruning, speaking & searching."

1. **GBrain** — Garry Tan's open-source personal brain. Email and calendar flow into a git repo; a nightly job re-links everything and flags what's gone stale.
2. **mem0** — a memory library called from your own code. Only stores what you explicitly tell it to, ranks fresh facts above idle ones at search time.
3. **Letta** — for agents that remember across sessions. The agent decides what's worth keeping; a second agent tidies up its memory in the background.
4. **Zep / Graphiti** — a knowledge graph with a clock in it. When a fact changes, the old one gets an end date instead of being overwritten, so you can ask what was true last March.
5. **Sylph** — a content brain that lives entirely in a git repo. Agents write drafts, humans publish, and the agent then reads the edits to learn what it got wrong.
6. **DIY (Claude Code + git)** — "what most engineering teams actually do." Markdown in the repo, grep instead of search, PRs as the only thing keeping it honest.
7. **Pletor** — a brand brain for marketing teams. Campaigns, assets, and performance data in one tree; brand rules only move when a human signs off.
8. **Gorgias Cortex** — built in-house by an 8-person AI team. 12,000 markdown nodes in GitHub; every night, the questions it got wrong become PRs that fix it.
9. **Slite Agent** — for teams whose knowledge lives in docs/across sources. Watches ~20 connected tools (Slack, Drive, GitHub, Jira, etc.) for what's gone stale and sends the diff to whoever owns the page. Nothing changes without human approval.
