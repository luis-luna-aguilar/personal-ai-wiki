# Proposal: Cognition — Introducing Devin Oncall

## Summary

### In short
Devin's production work has moved from triage to mitigation: Cognition made Devin Oncall generally available, and its Responders replace Auto-Triage with a parent agent that skips about 60% of alerts as known issues, a separate review agent that challenges premature root causes, and memory and skills that build up per organization. Cognition reports 100% end-to-end success on SREGym-Lite, and AngelList retired its in-house harness for it. The proposal rewrites the Devin page's Auto-Triage material, adds Devin to Agentic DevOps on State of Agents, and gives the infrastructure-operations training page its first production evidence. One hesitation: the post is undated.

[[#Open questions|Open questions: 1 to answer.]]

### The source
Cognition's launch post announces Devin Oncall as generally available: Devin investigates alerts and bug reports, diagnoses production incidents and mitigates them. Cognition says it now handles thousands of real production alerts a day. The headline benchmark is SREGym-Lite, 17 faults based on real incidents, where an agent must find the root cause and fix the live system in the same run. Devin Oncall scored 100% with several models, fastest with Opus 5.5 at 2 minutes 21 seconds; on the public leaderboard CloudThinker also reached 100%.

The argument is a Bitter Lesson one. Specialized AI SRE vendors, Cognition's own acquired TierZero included, compensated for weak models with essay-length runbooks, custom graph architectures and SRE-specific post-training, and those tricks now get in the way as models improve. So Oncall is a general coding agent plus three things: core intelligence (choosing the best model per task, and a second review agent that checks whether the investigator treated correlation as causation or mistook a recent deploy for the cause), company context (per-responder memory, skills generated by indexing the customer's environment, and organization memory distilled from past investigations), and agent behavior.

Behavior comes as two products. Responders, which Cognition calls the next generation of Auto-Triage, keep a hidden parent agent watching the alert stream that starts a fresh child investigation only for new issues. Incidents put Devin in the incident channel, where a parent investigates in the background and keeps a live incident document while child agents answer direct questions. Customer stories: at Reducto, Devin flagged an incident before the alerts fired and now fixes medium-severity issues or tests a PR before paging anyone; at RV Tech it does the first pass on customer reports; at AngelList it finds the right root cause 3.5 times as often as the in-house tool it replaced.

### What changes
The wiki describes Devin's Auto-Triage (May 2026) as an always-on Slack triage agent that diagnoses and tags owners. On State of Agents, Devin is listed only under Agent orchestration.

The post has no date; it cites a leaderboard snapshot of 15 October, so pages use the ingest date of 19 October. Listing Devin under both Agent orchestration and Agentic DevOps is a scope choice: Oncall belongs with the ops tools, while Security Swarm keeps the orchestration line.
