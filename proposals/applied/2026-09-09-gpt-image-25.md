# Proposal: GPT-Image-2.5 release

## Summary

### The source

OpenAI shipped GPT-Image-2.5 (ChatGPT Images 2.5) on 2026-09-08/09, largely overshadowed in coverage by the same week's Navier-Stokes and Meta Muse stories. The release is a straightforward version bump on speed and editing quality: up to 50% lower latency than Images 2.0, better realism, more consistent results across repeated edits, comment-based localized changes, transparent backgrounds, and a new Sketch tool for guided generation. Two API variants ship alongside it — Flare for speed/quality and Sunburst for higher-precision detail work. OpenAI's own Arena results claim #1 and #2 positions across text-to-image, image-edit, and multi-image-edit leaderboards, with the largest gains in multi-image editing specifically. Integrations landed the same day on fal, Higgsfield, Manus, and Hermes Agent.

### What changes

The wiki's **GPT-Image-2** page currently reflects the original April 2026 launch (#1 across all image-arena categories at that time).

- **GPT-Image-2** gains a lightweight version-bump update: the 2.5 facts above, folded into the existing page rather than spun out separately, plus one new Recent-changes entry. Page date moves to 8 September.
