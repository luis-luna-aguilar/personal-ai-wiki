# Proposal: Microsoft Copilot Cowork goes GA

## Summary

Microsoft Copilot Cowork is now generally available to all Microsoft 365 users globally, with model choice, usage-based billing, and cost controls. Microsoft claims 30-40% cheaper per prompt than Claude Cowork. A follow-up report suggests Microsoft may pursue Microsoft-hosted DeepSeek as a cheaper backend option as unlimited-pricing tiers become unsustainable.
