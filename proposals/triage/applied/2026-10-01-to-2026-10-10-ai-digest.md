- [x] **[agents]** Every Agent: a production case study of one shared company agent on Claude Managed Agents, 80% cheaper after a cost hunt (high priority: 6 sources across two digests)

    **What it is:** Every launched @Every (10/6), one Slack agent shared by the whole company, replacing its "Plus One" fleet of per-employee OpenClaw agents that were "high-maintenance pets". Engineer Paridhi Agarwal's write-up explains the move to Claude Managed Agents (CMA): Anthropic runs the harness ("brain") separate from sandbox and tools ("hands"), each Slack thread is a session on an 8¢/hour VM, and app calls are proxied through Every's servers so the agent never holds a credential. Trade-offs: CMA only runs Claude (no cross-lab routing) and isn't eligible for zero-data retention; long sessions near the context limit returned empty replies, so idle DMs now roll into a fresh session with a recap (−39% total cost). A companion piece on cost: routing everything through a Sonnet coordinator that escalated to Opus raised costs and lowered quality; the biggest win was a broken prompt cache (per-user Slack IDs in memory-folder names made every system prompt unique), fixed for −74% in a best-case test, with >80% savings across 11 frequent tasks overall. Also: a small fast model decides whether to answer untagged thread messages. The agent saves successful workflows as skills anyone can run; the per-person agents mostly died off because they were hard to maintain and nobody remembered which did what, while people learned most from watching others' agents work in public threads. A FeanixBio field report (28-person agritech customer) shows daily ops sweeps and "summarize the agents" use, but also that the CEO stopped using it over beta-era costs; token spend fell about 60% after Opus 5.5.

    **Why it matters:** `training/ai-work-delegation-modes.md` already records Every's personal-to-shared pivot, and `training/company-wide-ai-enablement.md` still cites the Every Agent as "in-progress" (2026-08-11); the new material is the CMA production experience and shared-vs-personal agent evidence. - [x] **[agents]** Orchestration as code goes cross-vendor (Claude Managed Agents "flows", Devin Dynamic Workflows and trees) while measurements of agent teams stay mixed

    **What it is:** Claude Managed Agents dynamic workflows (public beta) let a lead agent write a phased plan, fan it out to up to 1,000 agents per run and merge the results, with Anthropic warning token use can be high. Q&A details: the model does not know its budget, but developers can set a session budget; subagents share a filesystem but cannot message each other; flows cost "much more" than one agent but find more; Anthropic's "dreaming" (research preview, distinct from Cognition's Devin Dreaming) rewrites a memory store from past transcripts to make repeated flows cheaper; and the Console graphs every lead-to-subagent payload.
