- [ ] **[coding]** Anthropic meters programmatic usage — billing overhaul triggers major developer backlash

    **What it is:** Starting June 15, Claude subscription plans will create a separate monthly credit pool for all programmatic usage (Agent SDK, `claude -p`, GitHub Actions, third-party apps). Pro gets $20 in credits; Max (20x) gets $200. These run at full API rates, separate from interactive Claude.ai and Claude Code chat usage. Previously, third-party harnesses were effectively subsidized at an estimated 70–90% below API pricing, so power users see this as a "rug pull." Developer backlash was swift and prominent: Theo (T3 Chat), Matt Pocock, Jeremy Howard, and others publicly cancelled or threatened to switch to OpenAI. Anthropic partially offset the damage by raising Claude Code weekly limits 50% through July 13, on top of a prior 2× 5-hour limit increase.

    **Why it matters:** Directly affects anyone building or using third-party Claude Code wrappers or Agent SDK apps. The ecosystem signal is clear: subscription-backed harnesses are not stable platform primitives — provider abstraction and BYOK are increasingly mandatory. Also accelerates developers evaluating Codex as an alternative.

- [ ] **[training]** Every's Plus One retrospective — individual per-person agents failed; shared task-specific agents work better

    **What it is:** Every gave every employee a personalized AI agent (Plus One, built on OpenClaw) and is now pivoting the product after a mixed internal experiment. Problems: agents frequently claimed they weren't connected to tools they actually were; gave "churlish yawning emoji" responses; didn't reliably follow directions; over-explained why they couldn't help. Some exceptions worked well (writing acceleration, bug tracking). The conclusion: one-AI-per-employee with its own personality was the wrong model. Next version of Plus One will operate as shared team resources with defined jobs, more like a contractor with specific scope than a personal assistant.

    **Why it matters:** Rare first-person account from a team that actually deployed per-person AI agents at a small-but-real company (Every). The lesson — individual "pet" agents vs. shared role-specific agents — is directly actionable for `training/` pages on agent deployment. Multiple articles already published on this.
