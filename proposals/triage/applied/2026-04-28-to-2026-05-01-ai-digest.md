- [x] **[agents]** Cost-aware agent evaluation is becoming first-class as coding agents show volatile token spend

    **What it is:** The Code highlights a Google paper on coding-agent spending and AINews summarizes related findings: coding agents can use orders of magnitude more tokens than chat/code reasoning, costs can vary heavily across repeated runs of the same task, and more spending does not always improve accuracy. The same batch also mentions Hugging Face eval cost concerns, benchmark instability, Princeton work on inconsistent agent evaluation, and shared eval-format efforts such as Every Eval Ever.

    **Why it matters:** This connects pricing, evaluation, and runtime control. Agent benchmarks that ignore cost, variance, and retry behavior are increasingly incomplete, especially as GitHub Copilot and Codex-style tools move toward usage-aware economics.
