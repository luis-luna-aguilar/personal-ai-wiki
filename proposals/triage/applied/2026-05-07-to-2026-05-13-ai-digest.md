- [x] **[training]** Perplexity's agent skill methodology — write evals first, not procedures

    **What it is:** Perplexity published its internal methodology for building agent skills that don't rot in production. Key principles: (1) Write 5–10 test cases *before* writing the skill — including negative examples (queries that should NOT invoke this skill). (2) Phrase triggers in natural user language ("babysit a PR", "watch CI") not technical phrases. (3) Write skill body in principles, not step-by-step procedures — the model knows commands, it needs direction. (4) When the agent fails in production, codify the failure as a standing instruction in the skill file. (5) Cut every line that the agent would get right without it.

    **Why it matters:** Strong candidate for `wiki/training/` — practical, evidence-backed, immediately applicable. Updates or creates a skills/agent-quality page.
