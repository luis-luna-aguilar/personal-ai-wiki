# AI-managed orchestration and local browser agents

AINews groups Sakana Conductor, local browser-agent demos, Cline Kanban, and MCP scoping guidance into a split between higher-level orchestrators and local-first agents. The through-line is a two-tier structure emerging in agent systems: a model-pool routing orchestrator at the top and lightweight local-first agents below it.

## Key claims extracted

- Sakana Conductor is described as an AI-managed orchestrator that routes tasks across a pool of available models
- Local browser-agent demos show agents running entirely in the browser (client-side) without cloud handoff for many tasks
- Cline Kanban provides a task-board view of active agent work
- MCP scoping guidance covers which tools and contexts to expose to which agents
- The split between high-level orchestrators and local-first agents is treated as a structural pattern, not a product-specific one

## Caveats

- AINews is a synthesis newsletter; Sakana Conductor and specific product details should be verified against primary sources
- Browser-local agent demos described are early-stage; production readiness not asserted
