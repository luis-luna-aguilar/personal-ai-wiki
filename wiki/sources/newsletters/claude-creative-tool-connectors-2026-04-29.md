# Claude creative tool connectors

Superhuman reports that Anthropic launched Claude connections for a wide range of creative production tools: Adobe, Blender, Fusion, Ableton, Splice, SketchUp, Affinity, and Resolume. This extends Claude beyond artifact generation into direct integration with professional creative-production software.

## Key claims extracted

- Claude connectors available for: Adobe (Creative Suite tools), Blender (3D/animation), Fusion (compositing/VFX), Ableton (music production), Splice (sample library), SketchUp (architectural/3D modeling), Affinity (design suite), Resolume (VJ/AV performance)
- Connectors position Claude as an agent inside the creative workflow rather than a separate chat interface
- Coverage source is Superhuman AI newsletter, not Anthropic's primary announcement page

## Caveats

- Superhuman is a secondary newsletter; exact connector capabilities and availability should be verified against Anthropic documentation
- The specific integration depth (read-only context, bidirectional tool calls, file export) is not described in the newsletter summary
