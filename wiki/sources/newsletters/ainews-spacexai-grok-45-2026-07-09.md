# AINews — SpaceXAI launches Grok 4.5

AINews' Twitter-recap coverage of the Grok 4.5 launch, compiling Elon Musk's and xAI/SpaceXAI's own framing plus Artificial Analysis' independent benchmark evaluation.

## Key claims extracted
- Grok 4.5 is 1.5T parameters, 3x larger than Grok 4.3 (per Artificial Analysis, relayed from Musk)
- Pricing confirmed: $2/M input, $6/M output; per Artificial Analysis, cache hits discounted 75% to $0.50/M and inputs over 200K tokens cost double
- Relative pricing comparison cited by users (@kimmonismus): Grok 4.5 $2/$6 vs. GPT-5.6 $5/$30 and Opus 4.8 $5/$25
- Positioning quotes: Musk — "Opus-class model, but faster, more token-efficient and lower cost" and "roughly comparable to Opus 4.7, but much faster"; xAI — "first model trained specifically for coding and agents"
- Context window: 500K, down from Grok 4.3's 1M (per Artificial Analysis); Musk said a return to 1M was expected "by next week"
- Artificial Analysis: #4 Intelligence Index (score 54, +16 vs. Grok 4.3, behind Fable 5/GPT-5.5/Opus 4.8); GDPval-AA v2 Elo 1543 (#4); top score on τ³-Banking (33%, above GPT-5.5 xhigh's 31%); Coding Agent Index 76 in Grok Build (on par with GPT-5.5 in Codex, below Fable 5 in Claude Code)
- Cost efficiency: $0.31 per Intelligence Index task, $0.49 per GDPval task, $2.59 per Coding Agent Index task; ~14K avg output tokens per Intelligence Index task (60%+ lower than Opus 4.8); 1.9M avg total tokens per Coding Agent Index task (vs. 7.2M for Fable 5 in Claude Code, 6.2M for GPT-5.5 in Codex)
- Day-0 ecosystem support: Grok Build/API/Cursor, Hermes Agent, OpenRouter, Grok subscriptions
