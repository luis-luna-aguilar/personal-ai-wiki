# Agent desktop apps as the new OS for knowledge work

Every argues that left-sidebar desktop apps combined with an agentic terminal or chat are becoming a universal interface for knowledge work. Codex, Claude, and Cursor are converging around the same surface: sidebars, connectors, terminals, skills, plugins, and persistent workflow state.

## Key claims extracted

- Left-sidebar desktop app + agentic terminal/chat is emerging as a default knowledge-work interface pattern
- Codex, Claude Cowork, and Cursor 3 all share structural UI similarity: sidebar navigation, embedded terminals, agent panels, connector slots
- "Sticky workflow state" — persistent per-project context that carries across sessions — is identified as the key switching cost that locks users into a particular agent desktop
- Every frames the competition as a platform race: whoever owns the workflow container wins the switching-cost lock-in

## Caveats

- Every is an editorial source; the convergence claim is analytical framing, not backed by product-usage data
- Switching-cost thesis is early-stage; real lock-in effects have not been measured
