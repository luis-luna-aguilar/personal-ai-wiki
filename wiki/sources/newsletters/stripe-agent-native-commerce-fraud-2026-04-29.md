# Stripe agent-native commerce and compute fraud

Every summarizes Stripe's view on how AI changes commerce and fraud. The core argument: AI shifts fraud from stolen payment cards toward stolen tokens, API credits, free trials, and unpaid compute bills, while agents are becoming autonomous economic participants who make purchases themselves.

## Key claims extracted

- Stripe frames AI as changing the fraud attack surface: from payment credentials toward compute credentials (stolen API keys, tokens, credits, free-trial abuse)
- "Compute is the new cash": stolen compute capacity has real economic value and is increasingly targeted
- Agents as economic participants: agents are starting to make purchases autonomously — comparing products, checking out, managing subscriptions — which creates new merchant and payment-flow design challenges
- Stripe sees agent-native commerce as a category: payment flows need to be designed for agents as users, not only humans
- Key fraud patterns: API key theft, credit-consumption abuse, free-trial farming by automated agents, unpaid compute invoices

## Caveats

- Every is an editorial newsletter; this is Stripe's stated perspective (via newsletter summary), not a formal Stripe research publication
- Specific fraud rate figures or attack volume numbers are not in the newsletter summary; verify before citing
