# China-origin open agent-model releases

AINews reports on a wave of China-origin open-weight model releases — including Xiaomi MiMo-V2.5, Kimi K2.6, and others — continuing competitive pressure across long context, agent tasks, open-ish licensing, and lower-cost deployment.

## Key claims extracted

- Xiaomi MiMo-V2.5 described as an open-weight model with strong long-context and agent-task performance
- Kimi K2.6 (Moonshot AI) continues in the cluster; long-context and agent-benchmark focus
- Other China-origin releases mentioned alongside, continuing the open-weight agent competition beyond DeepSeek alone
- Pattern across releases: pressure on long-context, agent tasks, open-ish licensing, and inference cost
