# Cursor SDK as programmable coding-agent runtime

Cursor released a TypeScript SDK that exposes the Cursor agent runtime for use outside the IDE — in CI pipelines, automations, cloud VMs, MCP servers, with model swapping, and embedded product agents. The durable signal: Cursor is expanding from an IDE seat product toward programmable agent infrastructure.

## Key claims extracted

- Cursor SDK is TypeScript; exposes the Cursor agent runtime headlessly (no IDE required)
- Use cases described: CI/CD pipelines, server automations, cloud VM deployments, embedded product agents, MCP server integrations
- Model swapping: the SDK allows switching underlying models without changing the harness code
- The SDK is positioned as "Cursor without the window" — the runtime layer separates from the UX layer
- This moves Cursor from a per-seat IDE license model toward an agent-infrastructure platform

- "Embedded product agents" framing is newsletter synthesis; specific partner or customer examples not confirmed
