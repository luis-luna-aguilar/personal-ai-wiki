# GLM-5.2 — top frontend coding open model (June 2026)

AINews and Superhuman coverage of Z.ai's GLM-5.2 release. Full technical breakdown including IndexShare mechanism, MTP improvements, anti-reward-hacking training story, and independent benchmark positions.

## Key claims extracted

- MIT license; 744B/40B active MoE; 1M context; $1.4/$4.4 per M tokens
- IndexShare: reuses one indexer across 4 sparse layers → 2.9× FLOPs reduction at 1M context
- MTP: +20% speculative decoding acceptance
- Two reasoning modes: high, max
- Anti-reward-hacking: LLM judge blocked suspicious tool calls, returned dummy info
- Benchmarks: FrontierSWE #3 | Design Arena #1 | Agent Arena #10/#1 open | Code Frontend #2 | Terminal-Bench 2.1: 81.0 (was 62.0 for GLM-5.1)
