# Devin

Cognition's autonomous coding agent, initially positioned as one of the first "fully autonomous software engineer" agents. Now expanding into persistent operational roles: Devin Oncall (generally available October 2026) investigates and mitigates production alerts and incidents, succeeding Auto-Triage (May 2026), Cognition's first always-on deployment. Cognition valued at $25B (May 2026).

## Current status (as of 2026-10-19)

### Devin Oncall

- **Devin Oncall (GA, October 2026):** investigates alerts and bug reports, diagnoses production incidents, and mitigates them (rollbacks, scale-ups, tested PRs); Cognition reports thousands of production alerts handled per day across customers. Two products: Responders and Incidents.
- **Responders** are the next generation of Auto-Triage: a hidden parent Devin watches an alert or bug-report stream, decides whether an alert is a new issue, and only then launches a fresh-context child investigation. Remembering known issues and grouping related alerts skips about 60% of investigations, cutting cost by more than half. Two default types, Alert Responders and Support + Bug Responders, are tuned to work without custom runbooks.
- **Incidents:** Devin joins the per-incident channel, keeps a live incident document, and investigates continuously as a parent agent while spawning child Devins to answer direct questions; channel messages are relevance-filtered before they reach it.
- **Reliability and context layers:** an asynchronous review agent checks the investigator's recent reasoning and tool calls for correlation treated as causation, dismissed contradictory telemetry, or a trigger mistaken for the root cause. Context comes from per-responder memory, per-org skills generated by indexing the customer's environment (e.g. customer blast radius), and per-org memory distilled from past investigations, which Cognition treats as a low-fidelity cache.
- **Results:** 100% end-to-end (root cause plus live mitigation) on SREGym-Lite's 17 faults, fastest with Opus 5.5 at 2m 21s; GPT-6 Astra also reached 100% in Devin, as did CloudThinker on the public leaderboard. AngelList reports 3.5x more correct root causes than its in-house harness Sky (since deprecated) and 50% of incidents handled end-to-end; Reducto has Devin take most engineering alerts first.

### Security Swarm and Agentic MapReduce

- **Security Swarm:** parallel agents fan out across a codebase for vulnerability discovery, validation, patching, and PR generation
- Security Swarm aggregates findings, reproduces each issue in a sandbox, validates exploitability, then writes a patch for review
- **Agentic MapReduce (the architecture behind Security Swarm):** a Plan agent studies the repo and authors deterministic "selectors" (Tree-sitter queries, symbol/type queries, import-graph traversals, lexical patterns); the selectors run over every file with no model in the loop (Shard), producing a bounded, inspectable work queue instead of an open-ended search; one fresh Devin session per batch investigates its shard in parallel (Map); a Reducer session dedupes findings and composes cross-shard attack chains, e.g. an unauthenticated ID leak plus an ID-gated RCE becoming one P0 (Reduce); a final Verify stage reproduces each serious finding in a sandboxed session against a running build and marks it Confirmed, False Positive, or Inconclusive
- Benchmarked against a CVE-pinned ground-truth set (GitHub Advisory Database, each pinned to the commit before its fix, dozens of cases across 12+ languages and vulnerability classes): Security Swarm reports **72% recall**, ahead of other scanners tested in the same eval, at a fraction of their cost
- Cognition claims the system finds more verified vulnerabilities at 30% lower cost than rivals; treat both this and the 72% recall figure as vendor-reported until independently verified, though the CVE-pinned methodology is more rigorous than a bare cost claim

### Fusion, productivity measurement, and models

- **Devin Fusion (preview):** applies the [sidekick multi-model harness pattern](../workflows/multi-agent-coordination.md) — a frontier model and a cheaper model run as two persistent, separately-cached agents, with the frontier model planning and reviewing while the sidekick handles mechanical work. Running on Fable 5, Fusion can beat Opus 4.8 on cost per task not because Fable is cheaper per token, but because stronger delegation and judgment waste fewer actions: per an independent coding-agent index analysis relayed by AINews, in 81% of sampled Fable-led runs the lead model never makes a code edit itself.
- On **FrontierCode Extended** (a cost-aware coding benchmark tracking both score and average cost per task), Fusion matches frontier-model performance at **35% lower cost** than running Opus 4.8 or GPT-5.5 alone, and **41% lower cost** when paired with Fable 5 (measured before Fable 5's access was suspended); internally, **88%** of Cognition's own merged PRs were driven entirely by the automated Fusion router
- **Session productivity estimator:** an automated system that reviews each completed Devin session, classifies whether it produced useful (typically merged) work, then estimates the equivalent human-engineering hours it saved; calibrated against 258 self-reported sessions from 126 users, reaching `r_log = 0.74` on held-out data, deliberately calibrated to underestimate rather than overestimate; now running in production with customers — Cognition frames this as the first automated system measuring AI engineering productivity in production
- **SWE-1.7 (July 2026):** a budget frontier coding model for Devin, post-trained from Kimi K2.7 inside Devin's own agent harness; per The Code's recap, Cognition claims it matches GPT-5.5 within a point on FrontierCode at roughly $2/task with Opus 4.8 slightly ahead (secondhand — tier and numeric score unspecified, Cognition's blog post not yet read); can summarize its own progress and resume where it left off, enabling coding sessions up to six hours

### Devin Outposts

- **Devin Outposts (July 2026):** Devin's planning/inference loop continues running in Cognition's cloud, but command execution, file edits, and repository access can now run on infrastructure the customer controls — a Mac mini, a lab GPU box, a private-network VM, or a Kubernetes cluster. Launch-partner deployment guides ship with Cloudflare (isolated edge sandbox), Daytona (sub-90ms snapshot-started sandboxes), E2B (fast configurable cloud sandboxes reaching into a private cloud), Modal (same GPU infra used for training/serving, so Devin can reproduce failures on production hardware), and Namespace (M5-powered Mac with Xcode/computer use for Apple-platform apps).

## Why it matters

Devin Oncall turns Auto-Triage, Cognition's first persistent always-on agent, into a full on-call product that mitigates as well as diagnoses. The parent/child structure (one manager watching the stream or the incident channel, many fresh-context workers investigating) is a concrete production instance of the [mayor + polecats orchestration pattern](../workflows/multi-agent-coordination.md), and the separate review agent is a production form of the challenge step that [agentic infrastructure operations](../training/agentic-infrastructure-operations.md) otherwise leaves to a human. Cognition's broader claim is a Bitter Lesson one: overfit runbooks, custom graph architectures and SRE-specific post-training age badly as models improve, so the durable core is a strong general coding agent plus context, tools and workflows.

Security Swarm extends the same architecture into enterprise security work, and Cognition has now named and documented the underlying pattern as [Agentic MapReduce](../workflows/multi-agent-coordination.md): deterministic selection guarantees whole-repo coverage, parallel bounded workers keep cost proportional to relevant code rather than repo size, and a reasoning Reduce step connects findings that isolated workers couldn't see on their own. Devin Fusion applies a different multi-model idea — [sidekick harnesses](../workflows/multi-agent-coordination.md), contrasted with the [Advisor strategy](../workflows/advisor-strategy.md) pattern by keeping both models' contexts persistently cached instead of paying a cache-miss cost per escalation. The productivity estimator is a production instance of [dollar/hours-denominated agent evals](../concepts/economic-agent-evals.md).
