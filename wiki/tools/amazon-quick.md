# Amazon Quick

Amazon's reported desktop work-context assistant. Described as building a personal knowledge graph from local files, calendar, and Slack, and integrating with Kiro CLI and Claude Code for project-aware coding and knowledge workflows.

- Reported integrations: Kiro CLI, Claude Code

## Why it matters (if verified)

A personal knowledge graph that spans files, calendar, and team communication — and connects to coding agents like Claude Code and Kiro CLI — would close a persistent gap: coding agents that have no awareness of what the developer or PM is actually working on or planning.
