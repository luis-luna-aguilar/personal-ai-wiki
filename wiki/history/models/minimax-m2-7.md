# MiniMax M2.7 (archived)

**Superseded by [MiniMax M3](../../models/minimax-m3.md) (June 2026).**

MiniMax M2.7 was an open-weight coding and agent model positioned as one of the most attractive "cheap but capable" models for agentic coding work.

- 220B-parameter MoE model for coding and general agentic tasks
- 30-50% of the RL team's own workflows assisted by an earlier checkpoint during development
- 56.22% SWE-Pro, 55.6% VIBE-Pro
- Native multi-agent collaboration; 97% skill adherence across 40+ tools
- Pricing: ~$0.30 / $1.20 per million input/output tokens
